# Parcel

Parcel is a zero-configuration web app bundler that handles JavaScript, CSS and HTML out of the box. It resolves dependencies, transforms and optimizes code, and provides live reloading, code splitting and tree-shaking by default, which makes it a good fit for rapid prototyping. The latest release is Parcel 3, currently in alpha, a ground-up rewrite of the bundler in Rust. It ships as a single native binary with no dependency on Node, drops most disk caching in favor of fast cold builds, and supports native plugins written in Rust, Go or Swift alongside JavaScript plugins that run on an embedded runtime. Its authors report builds up to 100x faster than version 2.
