# Graph Data Structure

Shortest path algorithms find the minimum-cost route between two nodes in a weighted graph. Different algorithms suit different scenarios: Dijkstra's handles non-negative weights, Bellman-Ford handles negative weights, and A\* uses heuristics for faster pathfinding. These algorithms underlie GPS navigation, network routing, and game AI.
