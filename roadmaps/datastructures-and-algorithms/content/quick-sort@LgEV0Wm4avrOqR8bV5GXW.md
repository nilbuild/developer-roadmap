# Quick Sort

Quicksort selects a pivot element and partitions the list so that all elements smaller than the pivot come before it and all larger elements come after. It then recursively sorts each partition. Average-case performance is O(n log n), but worst-case is O(n²) if the pivot is consistently poorly chosen. In practice, quicksort is often the fastest general-purpose sorting algorithm.
