# Insertion Sort

Insertion sort builds a sorted list one element at a time by taking each new element and inserting it into its correct position among the already-sorted elements. It runs in O(n²) in the worst case but is efficient for small or nearly sorted lists, where it approaches O(n). It is also the basis for more advanced algorithms like Timsort.
