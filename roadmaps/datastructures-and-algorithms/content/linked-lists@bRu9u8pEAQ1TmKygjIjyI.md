# Linked Lists

A linked list is a sequence of nodes where each node stores a value and a reference to the next node. Unlike arrays, linked lists do not require contiguous memory, making insertions and deletions at the head or middle efficient. The trade-off is that accessing an element by index requires traversing from the start.
