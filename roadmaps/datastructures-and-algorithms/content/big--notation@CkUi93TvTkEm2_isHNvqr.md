# Big-Ω Notation

Big-Ω (Omega) notation describes the lower bound of an algorithm's growth, representing the best-case scenario. If an algorithm is Ω(n), it will always take at least linear time. It is less commonly used than Big-O but useful when analyzing minimum guaranteed performance.
