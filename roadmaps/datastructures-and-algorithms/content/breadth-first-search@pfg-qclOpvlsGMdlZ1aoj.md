# Breadth First Search

Breadth-first search (BFS) explores a tree level by level, visiting all nodes at the current depth before moving deeper. It uses a queue to track nodes to visit next. BFS is useful for finding the shortest path in unweighted graphs and for level-order traversal of trees.
