# Backtracking

Backtracking builds a solution incrementally and abandons a path as soon as it determines the path cannot lead to a valid solution. It explores possibilities using recursion and prunes branches early to reduce the search space. Common uses include solving puzzles like Sudoku, generating permutations, and the N-Queens problem.
