# Serving over Internet

Serving GraphQL over the internet involves making a GraphQL server accessible to clients through a public IP address or domain name. This can be done using reverse proxies, cloud services, or serverless functions to expose the GraphQL endpoint publicly. For how the endpoint should handle methods, media types and status codes, follow the GraphQL over HTTP specification.

Visit the following resources to learn more:

- [@official@Introduction to Serving over HTTPs](https://graphql.org/learn/serving-over-http/)
- [@official@GraphQL over HTTP Specification](https://http-spec.graphql.org/September2026/)
