# Review Diffs

Every agent edit appears as a diff, so you can read, accept, reject or ask for changes line by line. The Agents Window adds a diffs view where you can commit and manage pull requests. In the CLI, `Ctrl+R` opens a review of the changes.

Visit the following resources to learn more:

- [@official@Agent overview](https://cursor.com/docs/agent/overview)
- [@official@Agents Window](https://cursor.com/docs/agent/agents-window)
