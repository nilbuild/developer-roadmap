# What is Agentic Loop?

An agentic loop is the cycle an agent repeats until a task is done. The model reasons over the current context, calls a tool such as searching files or running a command, observes the result and decides on the next step. In Cursor this loop is bounded by your run mode and approvals, so the agent pauses when it needs permission to go further.
