# What is a Coding Agent?

A coding agent is an AI system that completes programming tasks by taking actions, not just suggesting text. It can search many files, edit them, run shell commands, read the results and decide what to do next. Compared with autocomplete, you give it a goal and it carries out the steps while you supervise.
