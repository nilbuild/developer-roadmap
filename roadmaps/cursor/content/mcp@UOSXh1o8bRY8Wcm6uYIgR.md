# /mcp

`/mcp` manages MCP servers inside a session. `/mcp list` shows servers and their status, and `/mcp list-tools <server>` shows that server's tools. It uses the same configuration as `agent mcp`.

Visit the following resources to learn more:

- [@official@CLI slash commands](https://cursor.com/docs/cli/reference/slash-commands)
- [@official@MCP](https://cursor.com/docs/mcp)
