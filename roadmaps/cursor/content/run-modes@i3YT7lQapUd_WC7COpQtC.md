# Run Modes

Run modes control when the agent can run actions without asking you. Auto-review lets allowlisted calls run, sends shell commands to a sandbox when possible and checks the rest with a classifier. Allowlist runs only approved actions, and Run Everything runs every tool call automatically with no sandbox. You choose the mode in Settings under Agents.
