# Agent Window

The Agents Window is an agent-first interface for working with many agents across repositories and environments, including local, cloud and remote SSH. It adds a diffs view for reviewing, committing and managing pull requests, and it supports worktrees and handing tasks between local and cloud. Open it with `Open Agents Window` in the Command Palette, and return to the classic editor with `Open IDE`.
