# Canvas

Canvases are interactive views that open next to the chat, such as dashboards, audits and reports with sections, stats and tables. Cursor creates one when a visual format suits the task, or when you ask for one. You can refresh it with new data and publish a read-only snapshot link to teammates on paid team plans.

Visit the following resources to learn more:

- [@official@Canvas tool](https://cursor.com/docs/agent/tools/canvas)
