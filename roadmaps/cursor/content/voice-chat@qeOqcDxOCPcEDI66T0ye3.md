# Voice Chat

Voice chat is a realtime spoken conversation with an agent: you talk, it talks back, and you can hand it coding work without typing. You start it with the waveform button in the chat input when the input is empty. It works in the Agents Window, the editor, the web and the iOS app, and it is separate from dictation, which only turns speech into text.
