# --sandbox

`--sandbox` sets the sandbox mode to `enabled` or `disabled`. When enabled, commands run with limited file and network access. The setting persists, and `/sandbox` changes it inside a session.

Visit the following resources to learn more:

- [@official@Run modes](https://cursor.com/docs/agent/security/run-modes)
- [@official@CLI parameters](https://cursor.com/docs/cli/reference/parameters)
