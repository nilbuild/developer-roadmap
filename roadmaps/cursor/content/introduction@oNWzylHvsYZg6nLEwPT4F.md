# Introduction

Cursor is an AI code editor built around a coding agent. The agent searches your repository, reads files, edits code, runs terminal commands and reports what it changed. You can use it in the desktop editor, in a separate Agents Window, from the terminal with the Cursor CLI, in the cloud, and from your phone. These surfaces share the same agent, rules and MCP configuration.

Visit the following resources to learn more:
