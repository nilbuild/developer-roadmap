# /run-everything

`/run-everything [on|off|status]` toggles Run Everything or shows its state, and `/auto-run` is an alias. When it is on, the agent runs tool calls without asking. Turn it on only in environments where mistakes are cheap.

- [@official@CLI slash commands](https://cursor.com/docs/cli/reference/slash-commands)
