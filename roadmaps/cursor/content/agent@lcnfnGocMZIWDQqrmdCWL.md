# agent

`agent` starts the Cursor CLI in interactive mode. You can pass a starting prompt, for example `agent "explain this project"`. It opens in Agent mode by default, and you can switch modes with `Shift+Tab`. Run it from the root of your project, or set another folder with `--workspace`.

Visit the following resources to learn more:

- [@official@CLI overview](https://cursor.com/docs/cli/overview)
- [@official@CLI parameters](https://cursor.com/docs/cli/reference/parameters)
