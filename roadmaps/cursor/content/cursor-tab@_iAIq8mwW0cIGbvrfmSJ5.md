# Cursor Tab

Cursor Tab is AI autocomplete that suggests code from your recent edits, nearby code and linter errors. Press `Tab` to accept a suggestion, or `Cmd+Right Arrow` to accept one word at a time, and press `Tab` again to jump to the next predicted edit. It can change several lines and edit other files, and you can snooze it or turn it off for chosen file types.
