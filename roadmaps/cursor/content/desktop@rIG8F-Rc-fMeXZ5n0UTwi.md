# Desktop

The desktop editor is the classic Cursor experience: code editor, Agent side panel, Tab autocomplete and diff review in one window. Use it when you want to read and edit code while the agent works. It runs on macOS, Windows and Linux. Extensions come from the Open VSX registry, so a few VS Code extensions may be missing or behave differently.
