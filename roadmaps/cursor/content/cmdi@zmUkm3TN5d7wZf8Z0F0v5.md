# Cmd+I

`Cmd+I` (`Ctrl+I` on Windows and Linux) opens the Agent in the side panel. `Cmd+L` and `Cmd+K` also toggle the side panel. It is the fastest way to start a prompt from the editor.

Visit the following resources to learn more:

- [@official@Quickstart](https://cursor.com/docs/get-started/quickstart)
