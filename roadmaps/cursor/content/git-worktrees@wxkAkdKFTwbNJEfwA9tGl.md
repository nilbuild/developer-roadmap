# Git Worktrees

A Git worktree is a separate checkout of the same repository, so each agent task gets its own files and your main checkout stays untouched. In the Agents Window worktrees are built in, and in the editor you use `/worktree`. A `.cursor/worktrees.json` file defines setup steps such as installing dependencies and copying `.env` files.

Visit the following resources to learn more:

- [@official@Worktrees](https://cursor.com/docs/configuration/worktrees)
