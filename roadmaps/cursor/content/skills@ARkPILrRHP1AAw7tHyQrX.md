# Skills

Skills are portable, version-controlled packages that teach the agent how to do a specific task. A skill is a folder with a `SKILL.md` file, with a `name` and `description` in frontmatter, and it can include scripts, references and assets. Skills live in `.cursor/skills/` or `.agents/skills/`, load on demand to save context, and can be called manually by typing `/` and choosing the skill.

Visit the following resources to learn more:

- [@official@Skills](https://cursor.com/docs/skills)
