# Parallel Cloud Agents

Because each Cloud Agent has its own VM and branch, you can run many at the same time on different tasks. You can check on them from the Agents Window, the web, your phone, Slack, GitHub or Linear. Parallel runs are billed as usage at the model's rate, so watch your spend limit.

Visit the following resources to learn more:

- [@official@Cloud Agents](https://cursor.com/docs/cloud-agent)
- [@official@Cloud Agent best practices](https://cursor.com/docs/cloud-agent/best-practices)
