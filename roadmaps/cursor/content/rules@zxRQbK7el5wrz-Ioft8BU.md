# Rules

Rules are persistent instructions placed at the start of the model context. Project rules live in `.cursor/rules` as `.mdc` files with frontmatter that controls when they apply: always, when matching files are in context, when the agent decides they are relevant, or only when you mention them. Keep each rule short and focused, under about 500 lines.
