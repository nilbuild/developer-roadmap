# Scaling Cursor

Scaling Cursor means running more work at the same time without the tasks getting in each other's way. Git worktrees give each task its own checkout, subagents split work inside one task, and Cloud Agents run many tasks in parallel on their own machines.

Visit the following resources to learn more:

- [@official@Worktrees](https://cursor.com/docs/configuration/worktrees)
- [@official@Subagents](https://cursor.com/docs/subagents)
- [@official@Cloud Agents](https://cursor.com/docs/cloud-agent)
