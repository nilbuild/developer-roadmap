# CLI

Cursor CLI brings the same agent to the terminal on macOS, Linux and Windows. You install it with a one-line script, start it with `agent`, work interactively with Agent, Plan and Ask modes, or run one-off prompts with `-p` in scripts and CI. It reads the same rules and MCP configuration as the editor.

Visit the following resources to learn more:

- [@official@CLI overview](https://cursor.com/docs/cli/overview)
