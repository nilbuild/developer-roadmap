# Reasoning Efforts

Many models in Cursor come in variants with different reasoning effort, such as low, medium or high. Higher effort lets the model think longer, which can improve results on hard tasks but uses more tokens and takes more time. Fast is a separate option that speeds up responses at a higher price per token. The available levels and where you set them depend on the model and your Cursor version, and some plans fix them, for example Plus runs Cursor models at medium effort.
