# Advanced Features

Advanced features go beyond chat and code edits. The Browser tool lets the agent test your running app, Canvas shows results as interactive views, Voice Chat lets you talk to the agent, and `/goal` keeps it working on a long task until it is done.

Visit the following resources to learn more:

- [@official@Browser tool](https://cursor.com/docs/agent/tools/browser)
- [@official@Canvas tool](https://cursor.com/docs/agent/tools/canvas)
- [@official@Voice chat](https://cursor.com/docs/agent/voice-chat)
- [@official@Agent overview](https://cursor.com/docs/agent/overview)
