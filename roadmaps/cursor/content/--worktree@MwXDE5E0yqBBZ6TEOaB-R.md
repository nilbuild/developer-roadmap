# --worktree

`--worktree` (or `-w`) runs the agent in a new Git worktree, with a generated name if you give none. Use `--worktree-base` to base it on a branch and `--skip-worktree-setup` to skip the setup scripts in `.cursor/worktrees.json`. Your main checkout stays untouched.

Visit the following resources to learn more:

- [@official@Worktrees](https://cursor.com/docs/configuration/worktrees)
- [@official@CLI parameters](https://cursor.com/docs/cli/reference/parameters)
