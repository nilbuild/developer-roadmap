# Debug

Debug Mode finds root causes by collecting runtime evidence before changing code. The agent proposes hypotheses, adds log statements, asks you to reproduce the bug, reads the logs, applies a small fix and then cleans up the instrumentation. Use it for bugs where guessing from the code alone does not work.
