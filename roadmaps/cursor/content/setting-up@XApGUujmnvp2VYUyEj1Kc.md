# Setting Up

Setting up Cursor takes three steps. Install the desktop app, or the CLI if you work in a terminal, then sign in with your Cursor account and open a project folder. A one-click import can bring over your VS Code extensions, themes, settings and keybindings.

Visit the following resources to learn more:

- [@official@Quickstart](https://cursor.com/docs/get-started/quickstart)
- [@official@Install](https://cursor.com/help/getting-started/install)
- [@official@CLI installation](https://cursor.com/docs/cli/installation)
- [@official@Migrate from VS Code](https://cursor.com/help/getting-started/migrate-vscode)
