# Cursor vs Claude vs Codex

Cursor, Claude Code and Codex are all coding agents that read a repository, edit files and run commands, but they come from different places. Cursor is an editor-first product that lets you choose models from several providers, including its own Composer models. Claude Code is Anthropic's agent for Claude models, and Codex is OpenAI's agent for OpenAI models. The three share many conventions, so Cursor can load `AGENTS.md`, `CLAUDE.md`, and skills and subagents stored in the `.claude` and `.codex` folders.
