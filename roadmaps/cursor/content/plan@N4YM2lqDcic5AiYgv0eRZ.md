# /plan

`/plan` switches the CLI to Plan mode, shows the current plan, or submits a prompt in Plan mode when you add text. The agent researches and proposes an approach before editing code. `Shift+Tab` also rotates between modes.

Visit the following resources to learn more:

- [@official@CLI slash commands](https://cursor.com/docs/cli/reference/slash-commands)
- [@official@Plan Mode](https://cursor.com/docs/agent/plan-mode)
