# @ Mentions

Typing `@` in the chat input adds specific context to your prompt. You can mention files and folders, terminal output, previous chats, Git diffs such as your working state or branch, and the built-in browser. When you are not sure which files matter, you can skip mentions because the agent also searches by itself.

Visit the following resources to learn more:

- [@official@Context](https://cursor.com/help/customization/context)
