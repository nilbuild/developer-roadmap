# Web

You can start and follow Cursor agents from any browser at cursor.com/agents, and from the Cursor app on iPhone and iPad. Android users can install the web app as a PWA. On mobile you can start agents on cloud machines or your own machines, send follow-ups, review diffs and checks, merge pull requests, and dictate or talk to the agent. The web also covers tasks the mobile app does not, such as the editor, terminal and file browser, environments and secrets, MCP server management, and rule and skill configuration.

Visit the following resources to learn more:

- [@official@Mobile and web](https://cursor.com/docs/cloud-agent/mobile)
