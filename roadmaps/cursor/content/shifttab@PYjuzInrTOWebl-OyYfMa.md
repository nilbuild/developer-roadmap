# Shift+Tab

`Shift+Tab` rotates between modes. In the editor chat input it switches to Plan Mode, and in the CLI it cycles through Agent, Plan and Ask. Use it to move from asking, to planning, to building.

Visit the following resources to learn more:

- [@official@Plan Mode](https://cursor.com/docs/agent/plan-mode)
- [@official@CLI usage](https://cursor.com/docs/cli/using)
