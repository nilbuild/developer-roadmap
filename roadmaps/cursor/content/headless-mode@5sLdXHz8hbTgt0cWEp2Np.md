# Headless Mode

Headless mode runs the agent without the interactive interface, using `agent -p "prompt"` (the `--print` flag). By default changes are only proposed, so add `--force` to let it edit files. You choose `text`, `json` or `stream-json` output with `--output-format`, which makes results easy to use in scripts.

Visit the following resources to learn more:
