# Cmd+Enter

`Cmd+Enter` sends your message immediately and skips the queue while the agent is busy. When the agent has suggested changes to review, the same keys accept all of them. Plain `Enter` queues the message instead, and pressing it again or using `Send now` steers the agent at its next tool call.
