# Tab

In the editor, `Tab` accepts a Cursor Tab suggestion, and pressing it again jumps to the next predicted edit. In the CLI model picker, it edits the selected model. In the chat, the shortcuts page lists `Tab` as cycling to the next message.

Visit the following resources to learn more:

- [@official@Tab](https://cursor.com/help/ai-features/tab)
- [@official@Agent overview](https://cursor.com/docs/agent/overview)
