# Mobile

The Cursor app for iPhone and iPad lets you start agents on cloud machines or your own machines, follow them live and send follow-ups. You can review diffs and checks, merge pull requests, dictate or talk to the agent, and get notifications for running agents. It needs iOS or iPadOS 26.0 or later, and Android users can install the web app as a PWA.

Visit the following resources to learn more:

- [@official@Mobile app](https://cursor.com/help/ai-features/mobile-app)
- [@official@Mobile and web](https://cursor.com/docs/cloud-agent/mobile)
