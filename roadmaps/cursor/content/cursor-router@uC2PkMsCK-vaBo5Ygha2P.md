# Cursor Router

Auto lets Cursor choose the model for you. Cost mode favors lower token spend, while Balance and Intelligence use Cursor Router, which classifies each request by task type and difficulty and sends it to a suitable model. Cursor Router is available on Teams and Enterprise plans, and individual plans use Cost mode.
