# /debug

`/debug` toggles Debug mode, or runs a prompt in Debug mode when you add text. The agent collects runtime evidence before it changes code. It suits bugs that need real logs to understand.

Visit the following resources to learn more:

- [@official@CLI slash commands](https://cursor.com/docs/cli/reference/slash-commands)
- [@official@Debug Mode](https://cursor.com/docs/agent/debug-mode)
