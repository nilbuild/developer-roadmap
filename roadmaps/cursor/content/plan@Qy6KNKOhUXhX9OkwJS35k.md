# Plan

Plan Mode makes the agent research the code, ask clarifying questions and write an implementation plan before any code changes. You can edit the plan and then build it. Switch to it with `Shift+Tab`, or with `/plan` in the CLI. It works best for features that touch many files or have unclear requirements.
