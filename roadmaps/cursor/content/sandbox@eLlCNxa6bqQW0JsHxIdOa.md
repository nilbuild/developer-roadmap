# /sandbox

`/sandbox` configures sandbox mode and network access for commands the agent runs. It is the in-session version of the `--sandbox` flag. Settings persist between runs.

Visit the following resources to learn more:

- [@official@CLI slash commands](https://cursor.com/docs/cli/reference/slash-commands)
- [@official@Run modes](https://cursor.com/docs/agent/security/run-modes)
