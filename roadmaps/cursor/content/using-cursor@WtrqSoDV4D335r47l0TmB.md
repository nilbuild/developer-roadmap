# Using Cursor

Once Cursor is installed, most daily work follows one loop. You describe a task, the agent searches and edits code, and you review the diff before you keep it. The rest is learning how to steer that loop: choosing an agent mode, giving the right context, managing sessions, and setting how much the agent can do without asking.
