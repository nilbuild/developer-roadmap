# Customization

Customization lets you adapt Cursor to your project and your team. Rules and `AGENTS.md` hold standing instructions, skills package repeatable tasks, MCP connects external tools, plugins bundle these together, and hooks run your own scripts during the agent loop.

Visit the following resources to learn more:

- [@official@Customize Cursor](https://cursor.com/docs/customize-cursor)
- [@official@Rules](https://cursor.com/docs/rules)
- [@official@Skills](https://cursor.com/docs/skills)
- [@official@MCP](https://cursor.com/docs/mcp)
- [@official@Hooks](https://cursor.com/docs/hooks)
