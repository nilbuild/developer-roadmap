# Usage Limits

Current paid plans include one weekly pool of usage for Cursor models, shared across the editor, the CLI and Cloud Agents. Third-party models are not in the pool and draw on prepaid credit instead. When the pool runs out you can wait for the weekly reset, use prepaid credit or upgrade, and unused usage does not roll over. Older plans use two monthly pools plus optional on-demand usage.

Visit the following resources to learn more:
