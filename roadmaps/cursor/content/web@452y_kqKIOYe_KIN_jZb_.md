# Web

Cursor Web at cursor.com/agents lets you start and follow Cloud Agents from any browser. It also covers tasks the mobile app does not, such as the editor, terminal and file browser, environments and secrets, MCP server management, and rule and skill configuration. Agents started on the web also show up in the desktop app and on mobile.

Visit the following resources to learn more:

- [@official@Cloud Agents](https://cursor.com/docs/cloud-agent)
- [@official@Mobile and web](https://cursor.com/docs/cloud-agent/mobile)
