# worker

`agent worker` starts a private cloud worker that runs Cloud Agents on your own machine or infrastructure. This keeps code and execution in your environment. Options include labels, a pool mode for one agent at a time, and `--computer-use` to let agents control the desktop. `agent worker debug` runs preflight checks.

Visit the following resources to learn more:

- [@official@Self-hosted agents](https://cursor.com/docs/cloud-agent/self-hosted)
