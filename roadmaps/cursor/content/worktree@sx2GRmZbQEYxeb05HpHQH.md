# /worktree

`/worktree <task>` is an editor chat command that runs the rest of a chat in a separate Git checkout. You can commit and push from there, bring the changes back with `/apply-worktree` and remove the checkout with `/delete-worktree`. It keeps experimental work away from your main checkout. In the Agents Window, worktrees are built into the interface instead.

Visit the following resources to learn more:

- [@official@Worktrees](https://cursor.com/docs/configuration/worktrees)
