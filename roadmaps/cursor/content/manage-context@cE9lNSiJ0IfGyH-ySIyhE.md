# Manage Context

Long conversations fill the model's context window and can lower the quality of answers. Run `/summarize` (alias `/compress`) to condense the conversation, start a new chat for each new task, and use `@` mentions to add only what the task needs. Side chats keep tangents out of the main thread.

Visit the following resources to learn more:

- [@official@Using the CLI](https://cursor.com/docs/cli/using)
- [@official@Context](https://cursor.com/help/customization/context)
- [@official@Side chats](https://cursor.com/help/ai-features/side-chats)
