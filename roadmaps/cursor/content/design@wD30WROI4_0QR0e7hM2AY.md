# Design

Design Mode lets you leave notes on your running app inside the browser of the Agents Window. You click an element, an area or text, describe the change, and the agent edits the code. Each note carries element details and a screenshot, so the agent knows exactly what you mean. Toggle it with `Cmd+Shift+D`.

Visit the following resources to learn more:

- [@official@Design Mode](https://cursor.com/docs/agent/design-mode)
