# Security Review

Security Review checks pull requests for security bugs, risky patterns and vulnerabilities before they merge. It runs as a Cloud Agent automation triggered by pull request events, and you can enable or disable the built-in checks and add custom instructions for your project. The /review-security skill runs the same review locally before you push, covering all branch changes against the base branch. Findings can be sent to tools such as Slack or an issue tracker through MCPs.
