# Ways to Use Cursor

Cursor runs in several places, and they share the same agent, rules and MCP configuration. You can work in the desktop editor, in the Agents Window, from the terminal with Cursor CLI, in the cloud with Cloud Agents, and from the web or your phone. Cursor also connects to GitHub, Slack, Linear and Jira, and the Cursor SDK lets you call the agent from your own code.

Visit the following resources to learn more:

- [@official@Cursor documentation](https://cursor.com/docs)
- [@official@Quickstart](https://cursor.com/docs/get-started/quickstart)
