# Subagents

Subagents are specialized assistants that the main agent delegates tasks to, each with its own context window. Built-in subagents such as Explore and Browser work automatically, and you can define custom ones as markdown files in `.cursor/agents/`. They can run in parallel or in the background, but each one uses its own tokens.
