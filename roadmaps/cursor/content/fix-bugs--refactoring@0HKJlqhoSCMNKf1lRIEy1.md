# Fix Bugs & Refactoring

Give the agent the error message, the steps to reproduce and the expected behavior. For bugs that are hard to explain, Debug Mode adds logging, asks you to reproduce the problem and finds the cause from real runtime data. The agent then makes a targeted fix and removes the logging. For refactoring, describe the change you want and ask the agent to run your tests afterwards to confirm that behavior did not change.
