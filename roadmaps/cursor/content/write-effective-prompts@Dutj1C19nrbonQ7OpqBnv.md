# Write Effective Prompts

Good prompts state the outcome, name the relevant files and describe how to verify the result. Use `@` to point the agent at specific files or folders, and keep tasks small enough to review. If the result is wrong, make the prompt more specific and run it again instead of patching a long conversation.
