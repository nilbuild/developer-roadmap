# Composer

Composer is Cursor's own agentic model family. The current version, Composer 2.5, is tuned for long tasks, tool use, file edits and terminal work inside Cursor. It draws from your plan's usage pool for Cursor models, and the faster variant is the default for interactive sessions at a higher price per token.

Visit the following resources to learn more:

- [@official@Composer 2.5](https://cursor.com/docs/models/cursor-composer-2-5)
