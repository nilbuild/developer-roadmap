# @

Typing `@` opens a picker to add files, folders, terminal output, past chats, Git diffs or the browser to your prompt. The agent then reads exactly what you pointed to. In the CLI it works for files and folders.

Visit the following resources to learn more:

- [@official@Context](https://cursor.com/help/customization/context)
- [@official@CLI usage](https://cursor.com/docs/cli/using)
