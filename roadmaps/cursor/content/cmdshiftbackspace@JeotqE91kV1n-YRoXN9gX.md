# Cmd+Shift+Backspace

`Cmd+Shift+Backspace` cancels the agent's current generation. When there are suggested changes to review, the same keys reject all of them, and `Cmd+Enter` accepts all of them. Use it to stop the agent quickly when it goes in the wrong direction.
