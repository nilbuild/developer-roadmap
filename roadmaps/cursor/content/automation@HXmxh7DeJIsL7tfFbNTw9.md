# Automation

Automation runs Cursor without you at the keyboard. Headless mode runs the agent from scripts and CI, GitHub Actions can call it in a workflow, Automations start Cloud Agents on a schedule or when an event happens, and Bugbot reviews pull requests for you.

Visit the following resources to learn more:

- [@official@Headless CLI](https://cursor.com/docs/cli/headless)
- [@official@GitHub Actions](https://cursor.com/docs/cli/github-actions)
- [@official@Automations](https://cursor.com/docs/cloud-agent/automations)
- [@official@Bugbot](https://cursor.com/docs/bugbot)
