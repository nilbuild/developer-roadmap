# Project Instructions

Project instructions are persistent guidance that Cursor places at the start of the model context. You write them as rules in `.cursor/rules` or as an `AGENTS.md` file, and you can add user rules for yourself and team rules for your organization. Use them for conventions the agent should follow every time, such as commands to run and code style.

Visit the following resources to learn more:

- [@official@Rules](https://cursor.com/docs/rules)
