# Bugbot

Bugbot is an automated pull request reviewer that looks for bugs, security issues and quality problems and leaves comments with fix suggestions. It runs on each PR update, or when you comment `cursor review` or `bugbot run`. Autofix can start a Cloud Agent to fix the findings, and you can add project guidance in `.cursor/BUGBOT.md`.

Visit the following resources to learn more:

- [@official@Bugbot](https://cursor.com/docs/bugbot)
