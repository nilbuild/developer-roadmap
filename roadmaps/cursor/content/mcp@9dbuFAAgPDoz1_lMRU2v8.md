# mcp

`agent mcp` manages MCP servers from the terminal. The subcommands `list`, `list-tools`, `login`, `enable` and `disable` show server status, show a server's tools, sign in to OAuth servers and control which servers are approved. The CLI reads the same `mcp.json` as the editor.

Visit the following resources to learn more:

- [@official@MCP](https://cursor.com/docs/mcp)
- [@official@CLI parameters](https://cursor.com/docs/cli/reference/parameters)
