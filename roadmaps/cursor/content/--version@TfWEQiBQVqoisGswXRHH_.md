# --version

`--version` (or `-v`) prints the installed Cursor CLI version. Run `agent --version` after installing to confirm that the install worked. The CLI updates itself by default, and `agent update` updates it manually.

Visit the following resources to learn more:

- [@official@CLI installation](https://cursor.com/docs/cli/installation)
- [@official@CLI parameters](https://cursor.com/docs/cli/reference/parameters)
