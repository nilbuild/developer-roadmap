# MCP

MCP (Model Context Protocol) connects Cursor to external tools and data sources such as issue trackers, databases and design tools. You configure servers in `.cursor/mcp.json` for a project or `~/.cursor/mcp.json` globally, using stdio, SSE or Streamable HTTP transports. Cursor asks for approval before running MCP tools, and remote servers can use OAuth.
