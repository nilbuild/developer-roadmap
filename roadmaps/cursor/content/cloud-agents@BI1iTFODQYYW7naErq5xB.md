# Cloud Agents

Cloud Agents run in isolated cloud VMs with a full development environment, so they keep working when your laptop is closed. Each agent clones your repository, works on its own branch, tests what it builds and opens a pull request with artifacts such as screenshots and logs. You can run many in parallel and start them from the editor, web, mobile, Slack, GitHub, Linear or the API. They were previously called Background Agents.
