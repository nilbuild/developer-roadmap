# Cmd+Shift+P

`Cmd+Shift+P` opens the Command Palette, which lists the commands that Cursor and your extensions provide. It is where you run `Open Agents Window` and `Open IDE`, and where you find Keyboard Shortcuts to see or change any key binding.

Visit the following resources to learn more:

- [@official@Keyboard shortcuts](https://cursor.com/docs/reference/keyboard-shortcuts)
- [@official@Agents Window](https://cursor.com/docs/agent/agents-window)
