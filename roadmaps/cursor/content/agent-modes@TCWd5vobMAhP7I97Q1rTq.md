# Agent Modes

Agent modes set how much the agent is allowed to do. Agent has full tool access, Ask is read-only, Plan researches the code and writes a plan before any change, Debug collects runtime evidence to find a root cause, and Design lets you annotate your running app. You switch modes with `Shift+Tab` or the mode picker.
