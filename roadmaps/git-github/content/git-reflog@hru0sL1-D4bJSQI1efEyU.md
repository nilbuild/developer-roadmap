# Git Reflog

A reflog, or reference log, records recent updates to local references such as HEAD and branch tips. It can help you find a commit after a reset or branch switch. Find the entry with `git reflog`, inspect the commit with `git show <commit>`, and run `git branch rescue <commit>` to save it on a separate branch. Your current branch and working tree stay in place.
