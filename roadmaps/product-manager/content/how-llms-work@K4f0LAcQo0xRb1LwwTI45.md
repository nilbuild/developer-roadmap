# How LLMs Work

A large language model (LLM) predicts the next piece of text, called a token, based on the text before it. It learns patterns from very large amounts of text during training. Because it predicts likely text instead of looking up facts, it can be wrong while sounding certain. Useful concepts for a PM are the context window, which limits how much text the model sees at once, and temperature, which controls how much answers vary.
