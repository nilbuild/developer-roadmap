# Reusable Prompts & Skills

A reusable prompt is an instruction you save and use again for a task you repeat, such as reviewing a PRD or summarizing a week of metrics. Skills package a prompt together with files and steps so an agent can run the whole procedure. Saving them makes results more consistent and lets teammates reuse your work. Start with the tasks you do every week.
