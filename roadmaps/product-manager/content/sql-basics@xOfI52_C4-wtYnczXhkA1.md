# SQL Basics

SQL is the language used to ask questions of a database. A PM with basic SQL can pull their own numbers with SELECT, filter with WHERE, group results, and join tables instead of waiting for an analyst. AI tools now write queries from plain language, but the PM still needs to read a query to check what it actually does. Wrong joins and wrong filters are common and produce believable but incorrect numbers.
