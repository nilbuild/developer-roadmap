# Feedback Loops

A feedback loop is a cycle where information from users flows back into decisions about the product. Sources include usage data, support tickets, reviews, surveys, and research. Strong loops are fast and regular: the team collects feedback, acts on it, and checks whether the change worked. Slow or missing loops mean problems are found late.
