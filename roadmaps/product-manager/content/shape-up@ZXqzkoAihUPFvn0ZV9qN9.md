# Shape Up

Shape Up is a product development method from Basecamp. Work runs in fixed six-week cycles, followed by a short cooldown. Before a cycle, a small group shapes a project: they define the problem and a rough solution, leaving room for the builders to decide the details. A betting table then chooses which shaped projects to build, and a small team owns each one from start to finish. It has no sprints or backlog.
