# User Story Mapping in Backlog Management

User story mapping is a technique for organizing user stories along two dimensions: the sequence of steps a user takes and the level of detail within each step. It gives teams a visual overview of the full user journey and helps identify gaps in coverage. It also makes it easier to plan releases by slicing the map horizontally by priority.
