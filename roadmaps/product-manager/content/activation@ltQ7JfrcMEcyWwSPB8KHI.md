# Activation

Activation is the moment a new user first gets real value from a product, such as sending a first message or creating a first project. It is different from signing up, because many people register and never reach this point. Teams define one clear activation event and then work to get more new users to it quickly. It is usually the strongest early predictor of whether a user will stay.
