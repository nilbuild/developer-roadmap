# Feedback Mining with AI

Feedback mining means using an AI model to read large amounts of raw customer feedback and pull out the main themes. The input can be support tickets, sales call transcripts, app store reviews, survey answers, and interview notes. The output is usually grouped themes with counts and example quotes. The PM still has to check the results against the original text, because models can invent quotes and overstate patterns.
