# Creating a Roadmap

Creating a roadmap involves gathering strategic inputs, identifying priorities, sequencing work logically, and presenting the plan in a format useful for its audience. It requires input from stakeholders, engineering capacity estimates, and clarity on goals. The output should be directional rather than a fixed delivery commitment.
