# Connectors & MCP

Connectors let an AI tool read from and act in your real work apps, such as Jira, Slack, Google Drive, and analytics tools. MCP (Model Context Protocol) is an open standard that defines how AI tools connect to these apps. With a connector, an agent can pull a live ticket or metric instead of working from a pasted copy. Each connection gives access to company data, so permissions need care.
