# AI App Builders

AI app builders are tools that create working web apps from a text description. Examples include Lovable, Bolt, v0, and Replit. A PM can use them to build a clickable or even functional prototype in an afternoon and put it in front of users. The code they produce is usually not ready for production, so they are best used for testing ideas and showing engineers what you mean.
