# Technical Fluency

Technical fluency is knowing enough about how software is built to work well with engineers. It includes understanding how front end, back end, databases, and APIs fit together, and what makes some changes cheap and others expensive. A PM does not write production code. The aim is to ask better questions, spot risks early, and make trade-offs with an accurate sense of effort.
