# Growth Loops

A growth loop is a cycle where the output of one step becomes the input of the next, so growth feeds itself. For example, a user creates content, the content is shared and found through search, and new users arrive and create more content. Loops differ from funnels, which are linear and need constant new input at the top. Teams look for loops that compound, such as referral, content, and viral loops.
