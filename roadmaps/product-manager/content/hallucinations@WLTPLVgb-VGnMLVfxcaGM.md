# Hallucinations

A hallucination is when an AI model produces something false but presents it as true, such as a made-up statistic, a fake citation, or a feature that does not exist. It happens because the model generates likely text instead of checking facts. Teams reduce it by giving the model reliable sources, asking it to cite them, and limiting what it is allowed to answer. It cannot be removed completely, so the product needs a plan for when it occurs.
