# Analyzing Data with AI

Analyzing data with AI means giving a model a spreadsheet, export, or database connection and asking it questions in plain language. It can clean data, write queries, build charts, and suggest explanations for changes in a metric. The PM must check the method and the numbers, since the model can pick the wrong column, apply a wrong filter, or state a guess as a fact. It works best for first-pass exploration, with important findings confirmed by an analyst.
