# Context Files

Context files are documents that give an AI agent lasting knowledge about your product, such as users, strategy, terminology, metrics, and writing style. They are stored as plain text or Markdown, often in a rules file the tool loads automatically. With them, the agent stops giving generic answers and writes in a way that fits your company. They need regular updates, because stale context produces confident but wrong output.
