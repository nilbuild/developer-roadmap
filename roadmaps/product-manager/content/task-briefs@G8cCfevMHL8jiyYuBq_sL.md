# Task Briefs

A task brief is a short written assignment for an AI agent. It includes the goal, relevant background, constraints, what files or sources to use, and what a finished result looks like. Without a brief the agent fills gaps with guesses. A brief that takes five minutes to write usually saves much more time in rework.
