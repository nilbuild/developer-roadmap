# Prompting Agents

Prompting an agent means giving it instructions that are clear enough to get useful work back. A good prompt states the goal, the context, the constraints, and the format of the answer. For longer tasks, many people ask the agent to make a plan first, review it, and only then let it run. The skill is closer to delegating to a new colleague than to searching on the web.
