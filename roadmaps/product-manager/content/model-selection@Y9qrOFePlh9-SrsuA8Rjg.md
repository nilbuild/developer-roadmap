# Model Selection

Model selection is choosing which AI model powers a feature. Most teams use models from providers through an API instead of training their own. The choice balances quality, speed, cost, context length, privacy terms, and reliability. A common approach is to prototype with the strongest model, test with an eval set, and then move to a cheaper one if quality holds.
