# Designing AI Features

Designing an AI feature is different from designing regular software because the output is not fully predictable. The same input can give different results, and some results will be wrong. The design has to decide how users see, correct, and trust the output. Key questions are where a human reviews the result, what happens when the model fails, and how the user knows what the feature can do.
