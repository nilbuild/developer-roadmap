# AI Tools for PMs

AI tools for PMs fall into a few groups. Chat assistants answer questions and draft text in a conversation. Coding agents work in a terminal or editor and can build and change software. Workflow tools run steps automatically on a schedule or when something happens. The right tool depends on the task, the sensitivity of the data, and what your company allows.
