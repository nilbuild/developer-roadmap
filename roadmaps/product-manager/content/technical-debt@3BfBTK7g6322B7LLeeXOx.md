# Technical Debt

Technical debt is the extra cost that builds up when a team chooses a quick solution now instead of a better one. It slows future work, increases bugs, and makes changes risky. Some debt is a reasonable trade-off, such as shipping fast to test an idea. A PM needs to make room for paying it down, since ignoring it eventually stops the team from delivering new features.
