# Feature Toggles

Feature toggles, also called feature flags, are switches in the codebase that allow teams to enable or disable specific features without deploying new code. They support gradual rollouts, A/B testing, and quick rollback if something goes wrong. Managing toggles well requires cleanup discipline to avoid accumulating permanent flags.
