# APIs & System Basics

An API (application programming interface) is a way for one piece of software to request data or actions from another. Most modern products are built from a front end, a back end, a database, and many APIs, including those of third-party services. A PM who understands this can read an API doc, discuss integrations, and understand why a change touches many parts. Terms worth knowing are request, response, endpoint, and rate limit.
