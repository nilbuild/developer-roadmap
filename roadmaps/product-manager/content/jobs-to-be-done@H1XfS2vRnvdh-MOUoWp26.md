# Jobs to Be Done

Jobs to Be Done (JTBD) is a research framework that describes what users want as the progress they are trying to make in a situation. A job is written like "when I need to report results to my boss, I want all the numbers in one place so I look prepared." It focuses on the situation and goal, not on who the user is. This helps teams see their real competition, which is often a spreadsheet or doing nothing.
