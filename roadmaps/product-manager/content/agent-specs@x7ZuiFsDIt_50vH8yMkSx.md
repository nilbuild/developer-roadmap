# Agent Specs

A spec for an agent is a requirements document written so an AI agent can build from it. It states the goal, the constraints, the expected behavior, and how to check that the result is right. Good specs include concrete examples and test cases, not only prose. The same document also works as the brief for human engineers, so the difference is mostly how precise it is.
