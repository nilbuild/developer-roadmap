# Agents

An AI agent is a system where a model decides what steps to take, uses tools like search or code execution, and repeats until a task is done. It differs from a single prompt and response because it works in a loop and acts on the world. Agents can handle longer tasks, but they also fail in more ways and cost more to run. PMs need to decide which tasks are safe to hand over and where a person must approve.
