# Heap Analytics

Heap is an analytics tool that automatically captures all user interactions without requiring manual event tracking setup. This makes it easier for teams to retroactively analyze behavior even for events that were not explicitly instrumented. It is useful for teams that need flexibility to answer unexpected questions about usage.
