# Real-Time Factor (RTF)

RTF measures how quickly an ASR system can process audio relative to its duration. A system that transcribes one hour of audio in six seconds has an RTF of 600x. It is the standard throughput metric for long-file transcription workloads and improves roughly linearly with the number of GPUs used for parallel chunk processing.
