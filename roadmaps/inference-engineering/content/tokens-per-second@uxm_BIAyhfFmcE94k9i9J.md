# Tokens Per Second (TPS)

TPS measures how many tokens are delivered to the user per second after the first token. It is determined by the decode phase and reflects memory bandwidth efficiency. Per-user TPS (also called perceived TPS) is a latency metric; total TPS across the inference service is a throughput metric.
