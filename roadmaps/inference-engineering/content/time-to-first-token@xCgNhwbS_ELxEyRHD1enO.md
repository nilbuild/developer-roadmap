# Time to First Token (TTFT)

TTFT measures how long it takes for a user to receive the first output token after submitting a request. It is determined primarily by the prefill phase and by queue time. For streaming applications like chatbots, TTFT is the most visible latency signal and directly affects perceived responsiveness.
