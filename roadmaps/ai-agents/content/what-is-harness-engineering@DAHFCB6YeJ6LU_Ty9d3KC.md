# Harness Engineering

Harness engineering is the practice of designing everything that surrounds a model in an AI agent system, so the model can do reliable work over long and complex tasks. The harness includes the agent loop, tool definitions, context and memory management, permissions and sandboxes, guardrails, and the feedback mechanisms (like tests, linters, and evals) that let the agent check its own work. The same model can perform very differently depending on its harness, which is why harness quality often matters as much as model choice.
