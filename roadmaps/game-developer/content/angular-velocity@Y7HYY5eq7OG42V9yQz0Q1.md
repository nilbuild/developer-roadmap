# Angular Velocity

Angular velocity is the rate at which an object rotates, represented as a vector whose direction is the axis of rotation and whose magnitude is the rotation speed in radians per second. In rigid body simulation, angular velocity is updated by integrating applied torques and is used to advance the object's orientation each frame. It couples with linear velocity through constraint solvers and collision response.
