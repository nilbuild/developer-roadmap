# Reflection

Reflection describes how light bounces off a surface back toward the viewer. In real-time rendering, reflections are approximated using techniques like cube maps, screen-space reflections, and planar reflection textures. Ray-traced reflections produce accurate results by tracing actual ray paths, but at higher computational cost.
