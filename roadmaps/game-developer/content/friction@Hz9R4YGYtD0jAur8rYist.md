# Friction

Friction is the force that opposes relative motion between surfaces in contact. In game physics, two types are modeled: static friction, which prevents an object from starting to slide, and kinetic friction, which opposes sliding motion. Friction coefficients are set per material and affect how objects slow down when sliding across surfaces.
