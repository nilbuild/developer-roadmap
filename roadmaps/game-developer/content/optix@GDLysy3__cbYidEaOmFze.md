# OptiX

OptiX is NVIDIA's GPU-accelerated ray tracing API and SDK, designed for high-performance offline and real-time ray tracing on CUDA-capable hardware. It provides a programmable pipeline for ray tracing with support for custom intersection, shading, and miss programs. OptiX is widely used in offline rendering, scientific visualization, and research rather than mainstream game development.

Visit the following resources to learn more:

- [@official@OptiX by Nvidia](https://developer.nvidia.com/optix/)
