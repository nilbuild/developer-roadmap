# C / C++

C and C++ are the dominant languages for game engine development and performance-critical game code. C++ offers object-oriented features, templates, and direct memory management, making it suitable for building engines, physics systems, and rendering pipelines. Most major game engines are written in C++ or expose C++ APIs for custom extensions.
