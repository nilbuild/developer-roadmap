# Fuzzy Logic

Fuzzy logic allows AI systems to work with degrees of truth rather than binary true/false values. In games, it is used to make NPC decision-making more gradual and natural, for example allowing a character to be "somewhat aggressive" rather than simply aggressive or not. Fuzzy systems define membership functions for each state variable and apply fuzzy rules to derive outputs.
