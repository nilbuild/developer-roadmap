# Catmull-Rom

A Catmull-Rom spline is a type of cubic spline that passes through all of its control points, making it convenient for path interpolation. Unlike Bezier curves, no separate tangent handles are needed because the tangents are computed automatically from the surrounding control points. Catmull-Rom splines are commonly used for camera paths and NPC waypoint movement because the curve naturally visits each waypoint.
