# Programming Languages

Programming languages are the tools used to implement game logic, engine systems, and tooling. Different languages suit different parts of game development: C++ for performance-critical engine code, C# for scripting in Unity, Python for tools, and Rust for systems programming. Language choice affects performance, iteration speed, and the size of the available ecosystem.
