# Computer Graphics

Computer graphics is the field concerned with generating and manipulating visual content using computers. In game development it covers rendering techniques, shading, geometry processing, and the mathematical foundations behind producing images from 3D scenes. Understanding computer graphics is required for working with rendering pipelines, shaders, and visual effects.
