# Bump

Bump mapping is a technique that perturbs surface normals at the pixel level to create the illusion of small-scale surface detail without adding geometry. The original method stored height values in a grayscale texture and derived normals from it. Normal mapping replaced it in most applications by storing the perturbed normals directly.
