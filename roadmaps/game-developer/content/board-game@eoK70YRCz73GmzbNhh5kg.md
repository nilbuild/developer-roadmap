# Board Game

Board game AI refers to techniques for building agents that play turn-based strategy games like chess, checkers, Go, and similar abstractions. These games have well-defined rules and discrete state spaces, making them natural benchmarks for AI algorithms. Tree search methods like minimax and Monte Carlo Tree Search dominate this area.
