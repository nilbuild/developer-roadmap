# State Machine

A finite state machine (FSM) is a model where an entity can exist in one of a finite set of states and transitions between states based on defined conditions. In game AI, FSMs control character behavior by mapping states like idle, patrol, and attack to specific actions and defining the triggers that switch between them. They are easy to implement but can become unwieldy with many states and transitions.
