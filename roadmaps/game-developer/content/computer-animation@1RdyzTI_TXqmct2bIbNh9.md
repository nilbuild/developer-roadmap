# Computer Animation

Computer animation covers techniques for producing motion in 3D scenes, including skeletal animation, blend shapes, procedural animation, and physics-based simulation. In games, animation systems must run in real time and blend smoothly between different motion clips based on gameplay state. Tools like animation state machines, inverse kinematics, and motion capture pipelines are all part of this area.
