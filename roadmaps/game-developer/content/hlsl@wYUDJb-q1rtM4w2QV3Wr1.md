# HLSL

HLSL (High-Level Shader Language) is the shader programming language used with DirectX. It compiles to GPU bytecode and supports all shader stages including vertex, pixel, compute, and ray tracing shaders. HLSL syntax resembles C and is the standard for shaders targeting Direct3D pipelines.
