# Physically-Based Rendering

Physically-based rendering (PBR) is a shading approach that models the interaction of light with surfaces based on physical principles such as energy conservation and the Fresnel effect. It uses standardized material parameters like base color, roughness, and metalness, which produce consistent results under different lighting conditions. PBR has become the standard shading model in modern real-time and offline rendering pipelines.
