# Client Side

Client side development in games refers to the code and systems that run on the player's machine, including rendering, input handling, audio, UI, and local game logic. It contrasts with server-side code in multiplayer games, which handles authoritative game state. Most single-player games are entirely client-side, while multiplayer games split responsibilities between client and server.
