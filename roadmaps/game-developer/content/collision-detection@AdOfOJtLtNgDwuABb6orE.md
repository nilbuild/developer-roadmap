# Collision Detection

Collision detection is the process of determining when and where two objects in a simulation intersect or make contact. It is divided into broad phase, which quickly eliminates non-colliding pairs, and narrow phase, which computes exact contact geometry. The output of collision detection feeds into the collision response system to resolve penetrations and apply impulses.
