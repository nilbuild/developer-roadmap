# Texture

Textures are 2D images applied to 3D surfaces to provide color, detail, or surface data like roughness and normals. They are sampled by shaders during rendering using UV coordinates mapped onto geometry. Mip-mapping and texture compression are used to manage memory and performance at different viewing distances.
