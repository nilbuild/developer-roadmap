# Decision Tree Learning

Decision tree learning is a supervised machine learning method that builds a tree model from labeled training data by recursively splitting the data on the most informative features. In game AI, it can be used to learn behavior rules from recorded gameplay or designer-specified examples. Algorithms like ID3 and CART are standard approaches.
