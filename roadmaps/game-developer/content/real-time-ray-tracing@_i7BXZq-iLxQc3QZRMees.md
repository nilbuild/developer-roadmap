# Real-Time Ray Tracing

Real-time ray tracing uses dedicated hardware acceleration, such as NVIDIA RTX or AMD RDNA ray tracing cores, to trace rays into the scene at interactive frame rates. It enables effects like accurate reflections, shadows, and ambient occlusion that are difficult to fake convincingly with rasterization. Real-time ray tracing is typically used selectively, combining traced rays with rasterized output to balance quality and performance.
