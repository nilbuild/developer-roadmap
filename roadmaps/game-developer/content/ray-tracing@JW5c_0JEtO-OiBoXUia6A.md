# Ray Tracing

Ray tracing is a rendering technique that simulates light by tracing paths from the camera through each pixel into the scene, calculating intersections with geometry and recursively following reflected, refracted, and shadow rays. It produces physically accurate shadows, reflections, and global illumination but is computationally expensive. Hardware-accelerated ray tracing is now available through APIs like DirectX Raytracing and Vulkan Ray Tracing.
