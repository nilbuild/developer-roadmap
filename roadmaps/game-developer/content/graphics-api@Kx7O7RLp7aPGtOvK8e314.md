# Graphics API

A graphics API is a software interface that allows applications to communicate with the GPU to submit rendering commands, manage resources, and control the rendering pipeline. Modern low-level APIs like Vulkan, DirectX 12, and Metal give developers more explicit control over GPU resources and synchronization compared to older APIs. Choosing an API determines which platforms the renderer can target and how much driver overhead is involved.
