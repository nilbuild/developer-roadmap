# Vulkan

Vulkan is a low-level, cross-platform graphics API developed by the Khronos Group. It offers explicit control over GPU memory, synchronization, and command submission, reducing driver overhead compared to OpenGL. Vulkan is used for high-performance rendering on Windows, Linux, and Android and serves as the foundation for MoltenVK on Apple platforms.
