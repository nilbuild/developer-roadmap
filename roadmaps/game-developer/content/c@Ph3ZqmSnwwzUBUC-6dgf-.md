# C Sharp

C# is a statically typed, object-oriented language developed by Microsoft and used as the primary scripting language in Unity. It runs on the .NET runtime and features garbage collection, LINQ, and strong tooling support. C# offers a balance between developer productivity and runtime performance suitable for game logic.
