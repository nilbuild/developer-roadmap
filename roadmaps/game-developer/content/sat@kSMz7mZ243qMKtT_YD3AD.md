# SAT

The Separating Axis Theorem (SAT) is a method for detecting collisions between convex shapes. It works by testing a set of axes and checking whether the projections of two shapes onto each axis overlap. If any axis produces a gap, the shapes are not colliding; if all axes show overlap, a collision is confirmed.
