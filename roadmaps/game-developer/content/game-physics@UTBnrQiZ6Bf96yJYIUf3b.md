# Game Physics

Game physics simulates physical behavior in a game world, including rigid body dynamics, collision detection, constraints, and fluid or soft body effects. Physics engines abstract the mathematics of Newtonian mechanics into systems that update object positions and velocities each frame. Popular physics middleware includes Bullet, PhysX, Havok, and Box2D.
