# Color

Color in computer graphics is represented using color models such as RGB, HSV, and CIELAB, each suited to different tasks. Understanding color spaces, gamma correction, and the difference between linear and perceptual workflows is important for producing consistent results across displays and rendering pipelines. Physically based rendering typically works in linear light space and converts to a display color space at the end of the pipeline.
