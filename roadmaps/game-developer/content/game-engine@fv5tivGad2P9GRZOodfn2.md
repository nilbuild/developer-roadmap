# Game Engine

A game engine is a software framework that provides the core systems needed to build and run games, including rendering, physics, audio, input handling, scripting, and asset management. Engines abstract away low-level platform details so developers can focus on gameplay logic and content. Examples include Unity, Unreal Engine, Godot, and custom in-house solutions.
