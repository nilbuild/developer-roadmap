# Python

Python is a high-level, dynamically typed language used in game development primarily for tooling, automation, and scripting. Its readable syntax and large standard library make it practical for build pipelines, content generation, and prototype logic. Godot supports Python-like GDScript, and some engines offer Python scripting bindings.
