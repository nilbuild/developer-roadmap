# Graphics Pipeline

The graphics pipeline is the sequence of stages that transforms 3D geometry into a final 2D image on screen. It includes stages like vertex processing, rasterization, fragment shading, and output merging. Modern pipelines expose programmable stages through vertex and fragment shaders, with newer APIs supporting additional stages like mesh shaders and ray tracing pipelines.
