# How to Write Prompts

Writing a good prompt starts with a clear statement of the task, the context the model needs and the format of the answer you expect. Be specific about what you want, explain the reason behind constraints, and describe what a good result looks like. Examples help when the style or structure is hard to describe. Test the prompt on several inputs and refine it based on what goes wrong.
