# Tools & Agents

Tools let a model act beyond generating text, for example by searching, querying a database or running code. Agents use tools in a loop and decide their own steps. Prompting for them means describing tools clearly, setting limits and keeping the context focused. Simpler fixed workflows are often more reliable than a full agent.
