# Context Failure Modes

Context failure modes are common ways that context causes bad output. Poisoning is when a wrong fact enters the context and keeps being reused. Distraction is when too much detail pulls the model away from the task. Confusion is when irrelevant material misleads it, and clash is when parts of the context contradict each other. Each one has a different fix.
