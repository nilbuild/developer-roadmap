# LLM-as-Judge

LLM-as-judge uses a model to score another model's outputs against criteria, such as accuracy, tone or completeness. It scales to many outputs where human review would be slow. Judges can be biased, for example toward longer answers, so clear rubrics are needed and results should be checked against human ratings.
