# Agent & Tool Security

Agent and tool security limits what an agent can do if it is misled or makes a mistake. Practices include giving each tool the least permissions it needs, running code in a sandbox, requiring human approval for risky actions such as deleting data or sending money, and treating tool results as untrusted input. Tool outputs can carry injected instructions.
