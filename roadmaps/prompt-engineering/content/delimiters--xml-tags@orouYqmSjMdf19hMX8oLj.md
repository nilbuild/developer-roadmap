# Delimiters & XML Tags

Delimiters are markers such as triple backticks, quotes or headings that separate one part of a prompt from another. XML tags like `<document>` and `<instructions>` do the same job and give each part a name you can refer to. They help the model distinguish instructions from data, and they make it harder for text inside the data to be mistaken for a command.
