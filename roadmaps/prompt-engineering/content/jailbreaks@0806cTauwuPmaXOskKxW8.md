# Jailbreaks

A jailbreak is a prompt that gets a model to break its own safety rules and produce content it would normally refuse. Common methods include role-play scenarios, encoded text and long multi-turn pressure. Providers train against known jailbreaks, but new ones keep appearing, so applications should not rely on the model's refusals alone.
