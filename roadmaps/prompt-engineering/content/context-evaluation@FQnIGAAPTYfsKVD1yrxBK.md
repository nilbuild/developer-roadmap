# Context Evaluation

Context evaluation checks whether the information given to the model is good, separately from the prompt. For RAG systems this means asking whether retrieval found the right documents, and whether the answer is supported by them. Measuring these two parts separately shows whether a failure comes from retrieval or from generation.
