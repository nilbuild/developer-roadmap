# Prompt Injection

Prompt injection is an attack where text in the input makes the model ignore its original instructions. It can be typed directly by a user, or hidden in content the model reads, such as a web page, an email or a document. It is hard to fully prevent, so defenses include separating trusted from untrusted content, limiting what the model can do and checking outputs.
