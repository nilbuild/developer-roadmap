# Prompt Templates

A prompt template is a prompt with placeholders, such as `{{customer_name}}`, that your code fills in at run time. It keeps the fixed instructions separate from the changing input, so the same prompt can be reused and tested. Templates also make versioning and evaluation easier, since only the variables change between runs.
