# Prompt Caching

Prompt caching lets a provider reuse the processed form of a repeated prompt prefix between requests. It lowers cost and latency when the beginning of the prompt stays the same, such as the system prompt, tool definitions and reference documents. To benefit, put stable content first and changing content, such as the user's message, last.
