# Tool Calling

Tool calling, also called function calling, lets a model request that your code run a function with specific arguments. You describe each tool with a name, a purpose and a JSON Schema for its inputs. The model replies with a tool request, your code executes it and returns the result, and the model uses it in its answer. Clear tool names and descriptions strongly affect how well the model picks the right one.
