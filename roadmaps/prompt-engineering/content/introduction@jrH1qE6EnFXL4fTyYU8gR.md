# Introduction

Prompt engineering is the practice of writing inputs that get useful, reliable outputs from a large language model. Context engineering widens the view to everything the model sees: instructions, retrieved documents, tool definitions, memory and conversation history. This roadmap starts with writing good prompts, moves on to managing context, and ends with evaluation and safety.
