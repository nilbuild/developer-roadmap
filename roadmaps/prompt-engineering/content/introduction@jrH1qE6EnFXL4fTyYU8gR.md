# Introduction

Prompt engineering is the practice of writing inputs that get useful, reliable outputs from a large language model. It involves clear instructions, examples, output formats and reasoning techniques such as chain of thought. Context engineering widens the view to everything the model sees: instructions, retrieved documents, tool definitions, memory and conversation history. Together they decide how well an LLM-based application performs, from a simple assistant to an agent.
