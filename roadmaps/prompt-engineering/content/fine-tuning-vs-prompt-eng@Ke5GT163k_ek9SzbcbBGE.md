# Fine-Tuning vs Prompt Eng.

Fine-tuning trains a model further on your own examples to change its behavior, while prompt engineering changes only the input. Prompting is faster, cheaper and easy to iterate on, so it is usually the first thing to try. Fine-tuning makes sense when you need a consistent style or format at scale, or a specialized task that prompts cannot reach.
