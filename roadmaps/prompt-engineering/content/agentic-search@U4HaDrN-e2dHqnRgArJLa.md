# Agentic Search

Agentic search lets a model run its own searches instead of relying on a single retrieval step. The model decides what to look for, calls search or file tools, reads the results and refines the query until it has enough information. It handles multi-step questions better than one-shot retrieval and needs no pre-built index in some cases. The cost is more tool calls, more latency and more tokens.
