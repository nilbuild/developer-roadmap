# CLAUDE.md & AGENTS.md

CLAUDE . md and AGENTS . md are markdown files kept in a project that coding agents read at the start of each session. They hold standing instructions such as build and test commands, code conventions and rules for the project. AGENTS . md is an open format used by several tools, and CLAUDE . md is the file Claude Code reads. Short, specific instructions work better than long ones.
