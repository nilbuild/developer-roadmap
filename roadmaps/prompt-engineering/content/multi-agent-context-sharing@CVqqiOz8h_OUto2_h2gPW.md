# Multi-Agent Context Sharing

In multi-agent systems, context sharing decides what information passes between agents. Sharing too little leaves an agent without what it needs, while sharing too much brings back the clutter that isolation was meant to remove. Common approaches are passing short summaries or structured results, using shared memory or files, and giving each agent only the parts relevant to its job.
