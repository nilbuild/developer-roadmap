# JSON Schema

JSON Schema is a standard way to describe the fields, types and required values of a JSON object. Many model APIs accept a schema and constrain the response to match it, so the output always parses and has the expected fields. The same format is used to define tool and function calls. A very strict schema can reduce answer quality, and support varies between models.
