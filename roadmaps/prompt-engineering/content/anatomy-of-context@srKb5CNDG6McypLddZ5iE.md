# Anatomy of Context

The context is everything the model sees in one request. It usually includes the system prompt, tool definitions, retrieved documents, memory, the conversation history and the latest user message. Each part uses tokens from the same window. Knowing what is in the context helps you find why a model behaves a certain way.
