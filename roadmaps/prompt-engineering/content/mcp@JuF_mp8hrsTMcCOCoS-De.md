# MCP

The Model Context Protocol (MCP) is an open standard for connecting AI applications to tools and data sources. A tool is exposed once as an MCP server and can then be used by any client that supports the protocol, instead of writing a custom integration for each app. Servers can provide tools, resources and prompt templates.
