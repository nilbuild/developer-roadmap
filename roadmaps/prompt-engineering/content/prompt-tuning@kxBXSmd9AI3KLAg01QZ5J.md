# Prompt Tuning

Prompt tuning trains a small set of learned vectors, called a soft prompt, that is added to the model's input while the model's weights stay frozen. It differs from writing prompts by hand, because the learned values are not readable text. It needs access to training and model internals, so it is mostly used with open models.
