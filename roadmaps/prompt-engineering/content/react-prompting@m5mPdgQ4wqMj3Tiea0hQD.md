# ReAct Prompting

ReAct prompting makes the model alternate between reasoning and acting. It writes a thought about what to do, takes an action such as a search or tool call, reads the result and repeats until it can answer. This loop is the basis of most agents. Modern tool calling has largely replaced hand-written ReAct prompts, but the pattern is the same.
