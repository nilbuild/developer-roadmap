# Classification & Routing

Classification and routing use a first model call to decide what a request is, then send it to the right prompt, model or tool. The prompt lists the options with clear descriptions, keeps them from overlapping and includes an "other" choice for unclear input. Code then reads the label and acts on it. Examples include support ticket triage and sending easy questions to a smaller model.
