# Context Compaction

Context compaction shortens the context when it grows too long. The usual method is to summarize older conversation turns or tool results and keep only the important facts, decisions and open tasks. Some systems also clear old tool outputs. It frees space and cuts cost, but a bad summary can lose details the model needs later.
