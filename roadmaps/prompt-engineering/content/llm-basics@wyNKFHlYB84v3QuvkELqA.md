# LLM Basics

An LLM generates text by predicting the next token from all the tokens before it, then repeating the process. Base models are trained on raw text and simply continue it, while instruct models get extra training to follow instructions and hold conversations. Most models you use through chat apps and APIs are instruct models. Knowing this explains why the wording, examples and context in a prompt change the output.
