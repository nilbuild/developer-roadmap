# Writing Tool Descriptions

A tool description is the text that tells a model what a tool does and when to use it. The model reads the tool name, the description and the parameter descriptions as part of its prompt, then chooses a tool based on them. Clear names, one distinct purpose per tool, and parameter descriptions with examples reduce wrong or missing tool calls. Ambiguous or overlapping tools are a common cause of agent mistakes, so these descriptions deserve the same testing as any other prompt.
