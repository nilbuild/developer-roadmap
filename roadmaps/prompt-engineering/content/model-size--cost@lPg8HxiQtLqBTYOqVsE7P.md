# Model Size & Cost

Models come in different sizes, from small and fast ones to large frontier models. Larger models are usually more capable but cost more per token and respond more slowly. Many applications use a small model for simple tasks and a large one only for hard requests. Pricing is normally charged per input and output token, so prompt length affects the bill.
