# Briefing Subagents

A briefing is the prompt an orchestrating agent writes to hand a task to a subagent. The subagent starts with an empty context, so the brief must include the goal, the relevant background, constraints, the expected output format and when to stop. Vague briefs lead to duplicated work, wrong assumptions or results that are hard to use. A good brief is written as if for a capable colleague who has seen nothing of the conversation.
