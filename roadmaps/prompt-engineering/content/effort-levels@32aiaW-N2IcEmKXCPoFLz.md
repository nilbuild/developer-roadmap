# Effort Levels

Effort levels control how much a reasoning model thinks before it answers. Providers expose this as a level such as low, medium or high, or as a token budget for thinking, and the names differ between them. More effort improves results on hard problems but increases cost and latency. For simple tasks a low setting is usually enough.
