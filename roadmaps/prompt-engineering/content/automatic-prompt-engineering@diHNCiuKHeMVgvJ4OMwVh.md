# Automatic Prompt Engineering

Automatic prompt engineering uses a model or an optimization tool to generate, test and select better prompts. You give it a task, example inputs and a way to score outputs, and it tries many variations. Frameworks such as DSPy follow this approach. Results depend on having a good eval set to score against.
