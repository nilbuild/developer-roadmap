# Calibrating LLMs

Calibration is how well a model's stated confidence matches how often it is right. LLMs often sound certain when they are wrong. You can ask for a confidence score or a set of levels, then compare these against real outcomes and set thresholds, for example sending low-confidence answers to a human.
