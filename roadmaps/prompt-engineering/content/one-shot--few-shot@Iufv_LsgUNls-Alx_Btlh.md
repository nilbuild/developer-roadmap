# One-Shot / Few-Shot

One-shot and few-shot prompting include one or several worked examples in the prompt before the real input. The model copies the pattern, which helps with output format, tone and unusual tasks. Examples should be consistent and cover varied cases, because the model tends to imitate them closely.
