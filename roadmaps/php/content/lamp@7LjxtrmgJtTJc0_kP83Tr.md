# LAMP

LAMP stands for Linux, Apache, MySQL, and PHP. It is a widely used open-source web server stack for deploying PHP applications in production. Each component handles a specific role: Linux as the OS, Apache as the web server, MySQL for the database, and PHP for server-side logic.

Visit the following resources to learn more:

- [@official@PHP Lamp](https://www.php.net/manual/en/introduction.php)
