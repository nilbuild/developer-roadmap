# Composer
 
Composer is the standard dependency manager for PHP. It reads a `composer.json` file to resolve and download packages from Packagist, records exact installed versions in `composer.lock`, and generates the autoloader. Nearly all modern PHP projects use Composer to manage third-party libraries.

Visit the following resources to learn more:

- [@official@Composer](https://getcomposer.org/)
- [@official@Composer Documentation](https://getcomposer.org/doc/)
