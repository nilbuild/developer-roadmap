# Dependency Injection
 
Dependency injection (DI) is a design pattern where a class receives its dependencies from outside rather than creating them internally. This makes classes easier to test and reduces coupling. In PHP, DI is typically implemented by passing dependencies through the constructor. DI containers automate this wiring in larger applications.
