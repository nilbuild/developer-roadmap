# MAMP

MAMP (Mac, Apache, MySQL, PHP) is a local server environment designed for macOS, though a Windows version also exists. It packages Apache or Nginx, MySQL, and PHP together and provides a graphical interface for managing them. MAMP Pro adds virtual hosts, dynamic DNS, and other features for professional use.
