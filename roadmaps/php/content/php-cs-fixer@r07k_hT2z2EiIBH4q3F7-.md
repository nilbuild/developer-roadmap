# PHP CS Fixer
 
PHP CS Fixer automatically reformats PHP code to comply with coding standards. It supports PSR standards and allows custom rule configurations. Unlike PHP_CodeSniffer, its primary mode is fixing rather than reporting. It is configured via a `.php-cs-fixer.php` file and integrates with editor plugins and CI workflows.

Visit the following resources to learn more:

- [@official@CS Fixer](https://cs.symfony.com/)
