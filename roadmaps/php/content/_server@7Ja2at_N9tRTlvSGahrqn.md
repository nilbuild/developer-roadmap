# $_SERVER

`$_SERVER` is a superglobal array containing information about the server environment and the current HTTP request. Common entries include `$_SERVER['REQUEST_METHOD']`, `$_SERVER['HTTP_HOST']`, `$_SERVER['SCRIPT_NAME']`, and `$_SERVER['REMOTE_ADDR']`. Its contents vary depending on the server and request context.
