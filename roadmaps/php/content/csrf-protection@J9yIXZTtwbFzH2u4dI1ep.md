# CSRF Protection
 
Cross-Site Request Forgery (CSRF) tricks authenticated users into submitting unintended requests. The standard defense is generating a unique, unpredictable token per session, embedding it in forms, and validating it on the server when the form is submitted. PHP frameworks typically include built-in CSRF middleware.
