# PHPStan
 
PHPStan is a static analysis tool for PHP that finds bugs by analyzing types and logic without running the code. It operates on configurable strictness levels (0–9), with higher levels catching more issues. PHPStan understands PHPDoc annotations and can be extended with custom rules for framework-specific patterns.

Visit the following resources to learn more:

- [@official@PHP Stan](https://phpstan.org/user-guide/getting-started)
