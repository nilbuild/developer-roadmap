# Default / Optional Params
 
Default parameter values are assigned in the function signature with `=`. When a caller omits that argument, the default value is used instead. Default values must be constants or expressions, not variables. Parameters with defaults must come after required parameters in the signature.

Visit the following resources to learn more:

- [@official@Default Parameters](https://www.php.net/manual/en/functions.arguments.php#functions.arguments.default)
