# Namespaces
 
Namespaces organize PHP code into logical groups and prevent naming conflicts between classes, functions, and constants in different libraries. They are declared with the `namespace` keyword at the top of a file. The backslash (`\`) is the namespace separator. Namespaces are essential in modern PHP applications using Composer-managed packages.

Visit the following resources to learn more:

- [@official@Namespaces](https://www.php.net/manual/en/language.namespaces.php)
