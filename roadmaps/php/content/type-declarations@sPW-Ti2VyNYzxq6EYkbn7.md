# Type Declarations
 
Type declarations specify the expected types for function parameters, return values, and class properties. PHP supports scalar types (`int`, `string`, `bool`, `float`), compound types (`array`, `callable`), class types, nullable types (`?Type`), union types (`Type1|Type2`), and the `mixed` type. Strict mode enforces types without implicit coercion.
