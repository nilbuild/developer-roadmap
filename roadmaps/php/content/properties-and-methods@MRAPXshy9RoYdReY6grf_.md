# Properties and Methods
 
Properties are variables defined within a class that hold an object's state. Methods are functions defined within a class that define its behavior. Both can be `public`, `protected`, or `private`, controlling their visibility. PHP 8 introduced promoted constructor properties to reduce boilerplate.

Visit the following resources to learn more:

- [@official@Properties and Methods](https://www.php.net/manual/en/language.oop5.properties.php)
