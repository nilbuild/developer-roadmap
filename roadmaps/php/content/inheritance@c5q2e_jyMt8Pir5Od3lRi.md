# Inheritance
 
Inheritance allows a class to extend another class, inheriting its properties and methods. The child class uses `extends` and can override parent methods or add new ones. PHP supports single inheritance only. The `parent::` keyword calls the parent class's method from the child class.

Visit the following resources to learn more:

- [@official@Inheritance](https://www.php.net/manual/en/language.oop5.inheritance.php)
