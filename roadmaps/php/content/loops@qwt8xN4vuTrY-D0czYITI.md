# Loops
 
Loops repeat a block of code multiple times. PHP supports four loop types: `while`, `do...while`, `for`, and `foreach`. The right choice depends on whether you know the iteration count in advance and whether you're iterating over a sequence or a condition. `break` exits a loop early; `continue` skips to the next iteration.
