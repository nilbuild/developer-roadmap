# Configuration Tuning
 
PHP's behavior is controlled through `php.ini` settings covering memory limits, execution timeouts, error reporting, upload sizes, and more. Tuning these settings for production involves balancing resource usage with application needs. Runtime configuration can also be overridden per-file using `ini_set()` for non-security-sensitive settings.

Visit the following resources to learn more:

- [@official@Configuration Tuning](https://www.php.net/manual/en/ini.core.php)
