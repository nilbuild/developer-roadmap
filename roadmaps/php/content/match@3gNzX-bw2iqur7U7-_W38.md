# match
 
The `match` expression works like `switch` but uses strict comparison (`===`) and returns a value rather than executing statements. Each arm maps one or more conditions to an expression. Unlike `switch`, there is no fall-through, and if no arm matches, PHP throws an `UnhandledMatchError`.

Visit the following resources to learn more:

- [@official@match](https://www.php.net/manual/en/control-structures.match.php)
