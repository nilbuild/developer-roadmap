# PHPUnit
 
PHPUnit is the de facto testing framework for PHP. It supports unit tests, integration tests, and test doubles (mocks, stubs, fakes). Test classes extend `PHPUnit\Framework\TestCase` and use assertion methods like `assertEquals()` and `assertNull()`. PHPUnit integrates with CI pipelines and code coverage tools.

Visit the following resources to learn more:

- [@official@PHP Unit](https://phpunit.de/getting-started/phpunit-7.html)
