# Yii
 
Yii is a high-performance PHP framework suited for developing large-scale web applications. It uses a component-based architecture and includes built-in support for caching, authentication, RBAC, and database access via its Active Record implementation. Yii 2 is the stable release; Yii 3 is a more modular redesign.

Visit the following resources to learn more:

- [@official@Yii Docs](https://yiisoft.github.io/docs/)
