# Zend Debugger
 
Zend Debugger is a PHP extension that enables remote debugging of PHP applications, typically within Zend-based development environments. It allows step-by-step execution, variable inspection, and breakpoints. It is less commonly used today compared to Xdebug but is found in enterprise setups using Zend Server.
