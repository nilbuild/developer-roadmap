# Database Connectivity > MySQLi
 
MySQLi is a MySQL-specific database extension that offers both procedural and object-oriented APIs. Like PDO, it supports prepared statements and bound parameters. MySQLi provides access to MySQL-specific features and is faster than PDO for MySQL-only applications in some benchmarks.

Visit the following resources to learn more:

- [@official@MySQLi](https://www.php.net/manual/en/book.mysqli.php)
