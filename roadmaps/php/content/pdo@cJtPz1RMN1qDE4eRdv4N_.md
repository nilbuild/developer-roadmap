# Database Connectivity > PDO
 
PDO (PHP Data Objects) is a database abstraction layer that provides a consistent interface for connecting to multiple database types, including MySQL, PostgreSQL, and SQLite. It supports prepared statements, which protect against SQL injection. PDO uses a DSN string to specify the driver and connection parameters.
