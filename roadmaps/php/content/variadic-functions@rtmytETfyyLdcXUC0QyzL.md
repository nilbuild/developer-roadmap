# Variadic Functions
 
Variadic functions accept a variable number of arguments using the `...` spread operator in the parameter list, like `function sum(...$numbers)`. All extra arguments are collected into an array. The spread operator can also be used in function calls to unpack an array into arguments.

Visit the following resources to learn more:

- [@official@Variadic Functions](https://www.php.net/manual/en/functions.arguments.php#functions.variable-arg-list)
