# Casting Data Types

Type casting in PHP converts a value from one type to another. You cast explicitly by placing the target type in parentheses before the value, like `(int)$value`. PHP also performs implicit type juggling in comparisons and arithmetic, which can lead to unexpected results if not accounted for.

Visit the following resources to learn more:

- [@official@Type Casting](https://www.php.net/manual/en/language.types.type-juggling.php)
