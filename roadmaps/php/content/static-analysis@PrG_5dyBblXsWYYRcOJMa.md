# Static Analysis
 
Static analysis examines PHP code for errors, type inconsistencies, and potential bugs without executing it. Tools analyze the codebase and report issues like undefined variables, incorrect method calls, or type mismatches. Static analysis catches bugs early in development and improves code quality over time.
