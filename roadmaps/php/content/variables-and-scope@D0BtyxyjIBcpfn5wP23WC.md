# Variables and Scope

Variables in PHP are declared with a `$` prefix and hold values of any type. Scope determines where a variable is accessible: variables defined outside a function are global and not accessible inside functions unless declared with the `global` keyword. PHP also supports static variables, which retain their value between function calls.
