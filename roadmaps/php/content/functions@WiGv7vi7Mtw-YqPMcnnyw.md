# Functions
 
Functions are reusable blocks of code defined with the `function` keyword. They encapsulate logic, accept parameters, and can return values. PHP includes a large standard library of built-in functions, and you can define your own. Functions in PHP support default parameters, variadic arguments, type declarations, and named arguments.

Visit the following resources to learn more:

- [@official@Functions](https://www.php.net/manual/en/language.functions.php)
