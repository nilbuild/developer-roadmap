# Multi-dimensional Arrays
 
Multi-dimensional arrays contain other arrays as values, creating a nested structure. They are used to represent tables, grids, or grouped data. Access follows chained bracket notation: `$matrix[0][1]`. PHP does not limit nesting depth, though deep nesting can make code harder to read.

Visit the following resources to learn more:

- [@official@Multi-dimensional Arrays](https://www.php.net/manual/en/language.types.array.php)
