# Interfaces
 
Interfaces define a contract of methods that implementing classes must provide. A class can implement multiple interfaces, unlike inheritance which is limited to a single parent. Interfaces contain only method signatures and constants, no implementations. They are used to define capabilities that unrelated classes can share.
