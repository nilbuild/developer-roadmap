# File Permissions

File permissions control who can read, write, or execute a file. PHP uses `chmod()` to set permissions programmatically and `fileperms()` to read them. On Unix-based systems, permissions follow the standard owner/group/other model. Incorrect permissions are a common cause of file operation errors in PHP applications.
