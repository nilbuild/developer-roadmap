# State Management

HTTP is stateless, so PHP uses sessions and cookies to maintain state between requests. Sessions store data on the server and identify the user with a session ID sent in a cookie. Cookies store small pieces of data directly in the browser. Together they enable features like login persistence, shopping carts, and user preferences.

Visit the following resources to learn more:

- [@official@setcookie](https://php.net/manual/en/function.setcookie.php)
