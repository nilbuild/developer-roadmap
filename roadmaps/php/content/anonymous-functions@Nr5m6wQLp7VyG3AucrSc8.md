# Anonymous Functions
 
Anonymous functions (closures) are functions without a name, typically assigned to a variable or passed as a callback. They are created with the `function` keyword and can capture variables from the surrounding scope using the `use` keyword. Arrow functions (`fn`) provide a shorter syntax for simple expressions.
