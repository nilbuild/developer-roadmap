# Give AI mockups, reference files, and material

AI coding tools produce much better results when they can see what you're aiming for instead of guessing from a short prompt. Share mockups or screenshots of the interface you want, point the tool to existing files that show your project's patterns, and include relevant material such as API docs, data schemas, or example inputs and outputs. Many tools also support project context files, such as `AGENTS.md`, that are loaded automatically so the model always has your conventions in view. Giving concrete references reduces back-and-forth and keeps the generated code consistent with the rest of your project.
