# Tell AI what NOT to do

When you notice an AI assistant repeating the same mistakes across sessions, such as adding unwanted dependencies, rewriting files you didn't ask it to touch, or ignoring your code style, turn those observations into explicit "do not" instructions. Keep them specific and pair each one with the preferred alternative, for example "don't add new date libraries; use the existing helpers in `src/utils`". Store these rules in your tool's project instructions or context files so they apply to every session instead of being repeated in each prompt, and review them as the project evolves.
