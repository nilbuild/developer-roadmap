# Elastic Load Balancers

Elastic Load Balancing distributes incoming traffic across multiple EC2 instances or targets. AWS offers three types: Application Load Balancer for HTTP/HTTPS traffic with content-based routing, Network Load Balancer for high-performance TCP/UDP routing, and Gateway Load Balancer for traffic inspection appliances. Load balancers also perform health checks and route traffic only to healthy targets.
