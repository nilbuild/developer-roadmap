# Public vs Private vs Hybrid Cloud

Public cloud refers to infrastructure shared across many customers and operated by a provider like AWS. Private cloud is dedicated infrastructure run by a single organization, either on-premises or hosted. Hybrid cloud combines both, allowing workloads to move between environments depending on cost, compliance, or performance requirements.
