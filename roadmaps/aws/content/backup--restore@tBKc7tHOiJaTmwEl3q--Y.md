# Backup / Restore

RDS performs automated backups of the database and transaction logs within a configurable retention window of up to 35 days. You can restore to any point in time within that window. Manual snapshots can also be created and kept indefinitely, independent of the retention policy.

Visit the following resources to learn more:

- [@official@Backup & Restore - RDS](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/CHAP_CommonTasks.BackupRestore.html)
