# Layers

Lambda layers are archives containing libraries, dependencies, or custom runtimes that can be shared across multiple functions. Instead of bundling dependencies in each deployment package, you attach a layer and Lambda makes its contents available to the function at runtime. Each function can use up to five layers.

Visit the following resources to learn more:

- [@official@AWS Lambda Layers](https://docs.aws.amazon.com/lambda/latest/dg/chapter-layers.html)
