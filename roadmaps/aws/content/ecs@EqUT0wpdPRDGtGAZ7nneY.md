# ECS

ECS (Elastic Container Service) is AWS's container orchestration service. It runs Docker containers on a cluster of EC2 instances or on Fargate without managing servers. ECS handles scheduling, scaling, and integrating containers with other AWS services.

Visit the following resources to learn more:

- [@official@Amazon Elastic Container Service (ECS)](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/Welcome.html)
