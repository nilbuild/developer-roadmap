# Primary Keys / Secondary Indexes

Every DynamoDB table requires a primary key, which uniquely identifies each item. A simple primary key uses just a partition key; a composite primary key uses a partition key and a sort key together. Secondary indexes, both local and global, allow querying the table on attributes other than the primary key.
