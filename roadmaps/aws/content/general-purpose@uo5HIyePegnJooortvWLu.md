# General Purpose

General Purpose SSD storage in RDS uses gp2 or gp3 volumes and is suitable for most database workloads. gp3 lets you provision IOPS and throughput independently from storage size, offering better cost control. This storage type is a good starting point unless your application has specific high-IOPS requirements.
