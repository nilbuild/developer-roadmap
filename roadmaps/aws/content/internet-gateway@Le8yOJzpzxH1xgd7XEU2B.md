# Internet Gateway

An Internet Gateway is a horizontally scaled, redundant component that connects a VPC to the internet. Attaching one to a VPC and adding a route in a public subnet's route table enables resources with public IPs to send and receive internet traffic. Each VPC can have one Internet Gateway attached.
