# Versioning / Aliases

Lambda supports versioning, which lets you publish immutable snapshots of a function. Each version has its own ARN and configuration. Aliases are named pointers to specific versions and can be used to route traffic between versions, enabling blue-green deployments or canary releases.

Visit the following resources to learn more:

- [@official@AWS Lambda Versioning](https://docs.aws.amazon.com/lambda/latest/dg/configuration-aliases.html)
