# RDS

RDS (Relational Database Service) is a managed service for running relational databases on AWS. It supports engines including MySQL, PostgreSQL, MariaDB, Oracle, SQL Server, and Amazon Aurora. RDS handles provisioning, patching, backups, and failover, so you can focus on the database schema and queries.

Visit the following resources to learn more:

- [@official@Amazon RDS](https://aws.amazon.com/rds/)
