# Configuration Sets

Configuration sets in SES are groups of rules applied to outgoing emails. They enable tracking of events like sends, bounces, complaints, and clicks by routing data to CloudWatch, SNS, Kinesis, or S3. You can also use them to apply dedicated IP pools or TLS settings.

Visit the following resources to learn more:

- [@official@SES](https://docs.aws.amazon.com/ses/latest/dg/using-configuration-sets.html)
