# Custom Runtimes

Lambda provides managed runtimes for languages like Python, Node.js, Java, and Go. For unsupported languages or custom configurations, you can provide a custom runtime using the Lambda Runtime API. The runtime is responsible for fetching events from Lambda and returning responses.

Visit the following resources to learn more:

- [@official@AWS Lambda Runtimes](https://docs.aws.amazon.com/lambda/latest/dg/lambda-runtimes.html)
