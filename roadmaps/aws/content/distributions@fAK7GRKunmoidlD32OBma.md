# Distributions

A CloudFront distribution is the configuration that defines how content is delivered. It specifies the origin (where CloudFront fetches content), cache behaviors, supported protocols, and geographic restrictions. You create one distribution per website or application, and it gets a unique CloudFront domain name.

Visit the following resources to learn more:

- [@official@Cloudfront Distribution](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/distribution-working-with.html)
