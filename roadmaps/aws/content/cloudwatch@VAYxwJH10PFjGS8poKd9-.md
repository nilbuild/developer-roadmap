# Cloudwatch

CloudWatch is AWS's monitoring and observability service. It collects metrics, logs, and events from AWS services and custom applications. You use it to set alarms, visualize performance data, and trigger automated responses to operational issues.

Visit the following resources to learn more:

- [@official@Amazon Cloudwatch](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.html)
