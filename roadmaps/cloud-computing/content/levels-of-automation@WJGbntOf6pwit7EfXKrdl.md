# Levels of Automation
 
Cloud automation exists on a spectrum. At the lowest level, engineers run manual commands through a console or CLI. Scripts automate repetitive tasks but require manual execution. Declarative IaC tools describe desired state and apply it automatically. At the highest level, self-healing systems detect and correct drift without human intervention, using control loops and event-driven automation. Moving up this spectrum reduces toil, improves consistency, and makes infrastructure auditable and repeatable.
