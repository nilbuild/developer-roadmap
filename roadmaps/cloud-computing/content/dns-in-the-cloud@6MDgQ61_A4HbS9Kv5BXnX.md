# DNS in the Cloud
 
Cloud DNS services resolve domain names to cloud resources and go beyond basic A record management. They support latency-based routing (directing users to the nearest region), geolocation routing, weighted routing for gradual traffic shifts, and health-check-based failover that automatically removes unhealthy endpoints. Route 53, Cloud DNS, and Azure DNS integrate directly with load balancers, CDNs, and other cloud services to enable these traffic patterns.
