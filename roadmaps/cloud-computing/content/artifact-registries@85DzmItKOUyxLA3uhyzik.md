# Artifact Registries
 
An artifact registry stores versioned build outputs produced by CI pipelines: container images, compiled binaries, and software packages. Registries sit between the build system and deployment targets, ensuring that what gets deployed is immutable, traceable, and consistent across environments. AWS ECR, Google Artifact Registry, and Azure Container Registry are the main managed options. Access control, vulnerability scanning, and image signing are standard features in production registries.
