# Distributed Systems

A distributed system is a group of independent machines that communicate over a network and work together as one system. Most cloud services are built this way, from load-balanced servers to replicated databases. Distribution brings scale and fault tolerance, but also network delays, partial failures and data consistency trade-offs such as the CAP theorem.
