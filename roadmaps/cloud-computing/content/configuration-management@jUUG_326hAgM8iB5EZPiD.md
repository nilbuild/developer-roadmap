# Configuration Management
 
Configuration management tools manage the state of software and settings on existing servers. Ansible, Chef, and Puppet are the main tools. Where IaC provisions infrastructure, configuration management configures what runs on it: installing packages, writing config files, managing services, and enforcing a desired system state. In cloud environments, configuration management is most relevant for managing fleets of VMs; container-based workloads largely replace it with immutable images built at CI time.
