# Object Storage
 
Object storage stores data as discrete objects, each consisting of the data itself, metadata, and a unique identifier, in a flat namespace without folder hierarchy. Access is through HTTP APIs rather than a filesystem interface. It is designed for massive scale, high durability (typically 11 nines), and low cost per GB. Object storage is the default choice for backups, media files, logs, static website assets, and data lake raw storage. AWS S3, Google Cloud Storage, and Azure Blob Storage are the primary implementations.
