# redis-benchmark

`redis-benchmark` is a built-in tool that measures Redis throughput by running a configurable number of commands against a live instance. It reports requests per second for each command type and helps establish performance baselines. Common uses include validating configuration changes and comparing hardware or network setups.

Visit the following resources to learn more:

- [@official@Redis Benchmark](https://redis.io/docs/latest/operate/oss_and_stack/management/optimization/benchmarks/)
