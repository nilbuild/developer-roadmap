# RedisBloom

RedisBloom adds probabilistic data structures to Redis, including Bloom filters, Cuckoo filters, Count-Min Sketch, and Top-K. Bloom filters allow fast membership testing with a configurable false positive rate and no false negatives. These structures are useful for deduplication and frequency estimation at scale.
