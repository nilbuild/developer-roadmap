# RedisJSON

RedisJSON is a Redis module that adds native JSON support. It allows storing, querying, and modifying JSON documents in place using a path-based syntax. Operations work on sub-documents without requiring the entire document to be fetched and re-serialized by the client.

Visit the following resources to learn more:

- [@official@RedisJSON](https://redis.io/json/)
- [@opensource@RedisJSON/RedisJSON - GitHub](https://github.com/RedisJSON/RedisJSON)
