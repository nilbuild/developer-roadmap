# Basic Commands / SET, GET

`SET` stores a value under a given key, and `GET` retrieves the value for that key. These are the most fundamental Redis commands and form the basis of all key-value operations. Both commands operate in O(1) time.

Visit the following resources to learn more:

- [@official@SET Docs](https://redis.io/docs/latest/commands/set/)
- [@official@GET Docs](https://redis.io/docs/latest/commands/get/)
