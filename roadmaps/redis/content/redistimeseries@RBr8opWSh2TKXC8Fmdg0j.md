# RedisTimeSeries

RedisTimeSeries is a module for storing and querying time-series data. It supports automatic downsampling, retention policies, and aggregation functions like average, min, and max over time windows. It is used for IoT data, metrics pipelines, and financial tick data.

Visit the following resources to learn more:

- [@official@RedisTimeSeries](https://redis.io/timeseries/)
- [@official@Time Series Documentation](https://redis.io/docs/latest/develop/data-types/timeseries/)
