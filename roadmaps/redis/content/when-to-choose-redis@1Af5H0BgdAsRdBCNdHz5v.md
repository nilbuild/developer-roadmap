# When to choose Redis?

Redis is a good choice when an application needs sub-millisecond response times for reads and writes. It fits use cases like caching, session storage, real-time leaderboards, and message queuing. It becomes less appropriate when durability, complex querying, or large datasets that exceed available RAM are requirements.
