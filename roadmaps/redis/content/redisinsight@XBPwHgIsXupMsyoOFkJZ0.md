# RedisInsight

RedisInsight is a graphical management tool for Redis provided by Redis Ltd. It allows browsing keys, running commands, viewing memory usage, and analyzing slow logs through a web-based UI. It supports standalone instances, Sentinel, and Cluster and is available as a free download.

Visit the following resources to learn more:

- [@official@RedisInsight](https://redis.io/insight/)
- [@opensource@RedisInsight/RedisInsight - RedisInsight Module on GitHub](https://github.com/RedisInsight/RedisInsight)
