# Deployment Workflow

A consistent deployment workflow defines how infrastructure changes move from development to production. Common patterns include environment promotion, where changes are applied to lower environments first, and GitOps, where the desired state is tracked in a Git repository and applied automatically. Enforcing a workflow reduces the risk of ad-hoc changes causing drift.
