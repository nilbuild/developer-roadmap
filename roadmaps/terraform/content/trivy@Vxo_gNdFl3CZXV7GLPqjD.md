# Trivy

Trivy is a security scanner that can analyze Terraform configurations for misconfigurations in addition to scanning container images and filesystems. It checks infrastructure code against a set of built-in rules and reports issues by severity. Trivy is easy to integrate into CI workflows and supports multiple output formats.
