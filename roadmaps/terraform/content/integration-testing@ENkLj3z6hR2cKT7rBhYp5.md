# Integration Testing

Integration tests provision real infrastructure and verify that resources are created correctly and work together as expected. They are slower and more expensive than unit tests but catch issues that static analysis cannot detect. Terratest is a popular Go-based framework for writing integration tests against live Terraform deployments.
