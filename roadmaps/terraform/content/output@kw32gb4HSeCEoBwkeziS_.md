# output

`terraform output` displays the values of outputs defined in the configuration. Without arguments it shows all outputs; a specific output name can be passed to retrieve a single value. The `-json` flag returns output in machine-readable format, useful for scripting.

Visit the following resources to learn more:

- [@official@Terraform output command](https://developer.hashicorp.com/terraform/cli/commands/output)
- [@article@Terraform output](https://learning-ocean.com/tutorials/terraform/terraform-output/)
