# TFLint

TFLint is a Terraform linter that goes beyond the checks provided by `terraform validate`. It detects errors specific to provider APIs, such as invalid instance types or unsupported regions, and can enforce custom coding rules through plugins. It is commonly run in CI pipelines alongside `terraform validate`.
