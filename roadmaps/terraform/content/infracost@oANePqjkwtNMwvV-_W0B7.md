# Infracost

Infracost is a cost estimation tool that integrates with Terraform to show the monthly cloud cost impact of planned infrastructure changes. It parses a Terraform plan and calculates costs based on provider pricing data. It can be added to CI pipelines to display cost breakdowns in pull request comments before changes are merged.
