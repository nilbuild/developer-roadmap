# Format & Validate

Terraform provides built-in commands for formatting and validating configuration files before deployment. These commands help maintain consistent style and catch configuration errors early, before a plan or apply is attempted.

Visit the following resources to learn more:

- [@official@Terraform Validate - Documentation](https://developer.hashicorp.com/terraform/cli/commands/validate)
- [@official@Terraform Format - Documentation](https://developer.hashicorp.com/terraform/cli/commands/fmt)
