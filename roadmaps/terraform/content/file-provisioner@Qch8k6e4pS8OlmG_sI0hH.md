# file provisioner

The `file` provisioner copies files or directories from the machine running Terraform to a newly created remote resource. It requires a connection block specifying how to reach the remote machine, typically over SSH or WinRM. It is commonly used to upload configuration files or scripts before executing them.

Visit the following resources to learn more:

- [@official@Terraform File Provisioner](https://developer.hashicorp.com/terraform/language/resources/provisioners/file)
- [@article@The File Provisioner](https://learning-ocean.com/tutorials/terraform/terraform-file-provisioner/)
