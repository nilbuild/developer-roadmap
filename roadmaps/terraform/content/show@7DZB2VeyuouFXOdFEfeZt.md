# show

`terraform show` displays a human-readable representation of the current state or a saved plan file. It is useful for reviewing what Terraform currently knows about managed resources without running a full plan. Passing a plan file shows the exact changes that will be applied.

Visit the following resources to learn more:

- [@official@Terraform show](https://developer.hashicorp.com/terraform/cli/commands/show)
- [@official@Terraform state show](https://developer.hashicorp.com/terraform/cli/commands/state/show)
