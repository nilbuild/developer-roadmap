# Terragrunt

Terragrunt is a thin wrapper around Terraform that adds support for keeping configurations DRY, managing dependencies between modules, and running commands across multiple modules at once. It uses `terragrunt.hcl` files to define module sources, variable inputs, and backend configuration. It is widely used in large multi-account or multi-environment Terraform setups.
