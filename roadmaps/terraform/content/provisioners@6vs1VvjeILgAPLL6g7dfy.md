# Provisioners

Provisioners run scripts or commands on local or remote machines as part of resource creation or destruction. They are a last resort for handling bootstrapping or configuration tasks that cannot be done through the provider API. HashiCorp recommends using purpose-built tools like cloud-init or Ansible instead where possible.
