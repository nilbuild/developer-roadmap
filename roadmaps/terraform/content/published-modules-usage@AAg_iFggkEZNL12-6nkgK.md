# Published Modules Usage

Published modules are pre-built, versioned modules available on the Terraform Registry. They can be referenced directly in a `module` block using a registry source address and version constraint. Using published modules speeds up development by providing tested, maintained implementations of common infrastructure patterns.

Visit the following resources to learn more:

- [@official@Publishing Modules](https://developer.hashicorp.com/terraform/registry/modules/publish)
- [@opensource@Terraform Registry - Modules](https://registry.terraform.io/browse/modules)
- [@video@Terraform - Publish modules](https://www.youtube.com/watch?v=9vBp1D3myH8)
