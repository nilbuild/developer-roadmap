# Integration Engineering

Integration engineering is the practice of connecting systems that were not designed to work together. This usually means building APIs over existing data layers, bridging incompatible authentication systems, chaining tools across services with different data formats, and wrapping third-party products in interfaces a new system can use reliably. Most of the technical difficulty in real-world AI deployments lives here, not in the model itself.
