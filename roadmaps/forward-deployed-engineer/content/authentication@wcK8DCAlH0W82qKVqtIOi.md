# Authentication

Authentication is the process of verifying the identity of a user or system. Common mechanisms include username/password, API keys, OAuth 2.0 tokens, and JWTs. Authentication is distinct from authorization, which governs what an authenticated user is allowed to do. Getting authentication right is foundational to securing any application that handles user data or sensitive operations.
