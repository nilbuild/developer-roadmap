# Cloud Platforms

Cloud platforms provide on-demand access to computing resources including servers, storage, networking, databases, and managed services. Instead of running physical hardware, teams deploy and scale their applications on cloud infrastructure. The major providers each offer a broad set of services that cover most infrastructure needs.
