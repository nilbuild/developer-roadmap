# Building Eval Pipelines

Evaluation pipelines are automated systems for measuring the quality of an AI model or application over a set of test cases. A good eval does not just check whether the final answer is correct. It traces the steps a skilled human would take to solve the same problem and grades the agent on each one. Building this starts with a golden dataset: a set of real queries with the ideal output labeled by hand. That becomes the standard everything else is measured against.
