# CSS

CSS, or Cascading Style Sheets, controls the visual appearance of HTML elements on a web page. It handles layout, colors, typography, spacing, animations, and responsive design. Modern CSS includes Flexbox, Grid, and custom properties that make it possible to build complex, adaptive layouts.
