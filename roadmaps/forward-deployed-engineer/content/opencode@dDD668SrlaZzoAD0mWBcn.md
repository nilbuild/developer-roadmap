# OpenCode

OpenCode is an open-source AI coding agent that runs in the terminal. It works with many model providers, including Anthropic, OpenAI, Google and locally hosted models, so you are not tied to a single vendor. It can read and edit files across a project, run shell commands and work through multi-step tasks. FDEs often work in customer environments with strict rules about which models and data can be used. A provider-agnostic, open-source tool lets them keep the same workflow when a customer approves only one provider, or requires a self-hosted model.
