# Prompt Engineering

Prompt engineering is the practice of crafting inputs to language models in a way that produces more accurate, useful, or reliable outputs. Techniques include zero-shot and few-shot prompting, chain-of-thought reasoning, role assignment, and structured output formatting. Good prompt engineering can significantly improve model behavior without any model fine-tuning.
