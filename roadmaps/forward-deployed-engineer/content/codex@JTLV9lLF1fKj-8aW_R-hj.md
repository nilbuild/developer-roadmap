# Codex

Codex is OpenAI's code-focused model, trained on large amounts of public code. It can generate code from natural language descriptions, complete functions, and help with documentation. It is the model that powers GitHub Copilot and one of the foundational tools that popularized AI-assisted coding as a mainstream workflow.
