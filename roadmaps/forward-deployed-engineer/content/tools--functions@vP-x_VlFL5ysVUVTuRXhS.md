# Tools & Functions

Tools and functions are the mechanisms through which AI agents interact with the outside world. A tool might query a database, call an external API, run a code interpreter, or search the web. In practice, tools are defined as schemas that the model can invoke, and the application handles executing the actual function and returning the result back to the model.
