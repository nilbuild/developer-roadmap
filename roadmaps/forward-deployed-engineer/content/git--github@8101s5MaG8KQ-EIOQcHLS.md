# Git & GitHub

Git is a distributed version control system that tracks changes to code over time and allows multiple people to collaborate on the same codebase without overwriting each other's work. GitHub builds on top of Git with features like pull requests, code review, issue tracking, and CI/CD integrations. Both are standard tools in nearly every software development workflow today.
