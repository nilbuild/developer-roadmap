# FDE Tiers

Not all FDE roles are the same. The job market has split into three distinct tiers with different skill requirements. AI lab FDEs need deep ML fluency, strong agent architecture skills, and the ability to help customers adopt models in production. Enterprise software FDEs need data platform depth, integration experience, and the ability to connect a vendor's product to a customer's existing data infrastructure. Consulting and staffing FDEs need broad solutions architecture skills, account management instincts, and the ability to run an end-to-end engagement independently. Knowing which tier you are targeting shapes which parts of this roadmap to prioritize.
