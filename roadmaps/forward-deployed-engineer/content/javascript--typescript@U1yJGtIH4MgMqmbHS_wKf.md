# JavaScript / TypeScript

JavaScript is the programming language of the web, running natively in browsers and on servers via Node.js. TypeScript is a superset of JavaScript that adds static type annotations, catching errors at compile time and improving code maintainability at scale. Together they are the dominant choice for full-stack web development.
