# Fable

Claude Fable is the most capable model family in Claude Code, built for demanding reasoning and long-horizon agentic work such as agent sessions that run for hours, deep research and root-cause investigations. Fable 5.2 (claude-fable-5-2) is the current version, released on November 9, 2026, and you select it with /model fable, which needs Claude Code v2.1.321 or later. It has a 1M token context window, always uses adaptive thinking, and costs $8 per million input tokens and $40 per million output tokens on the API, and depending on your plan its usage can bill to usage credits.
