# Fable

Claude Fable is the most capable model family in Claude Code, built for demanding reasoning and long-running agentic work such as root-cause investigations and architecture decisions. Fable 5.1 (claude-fable-5-1) is the current version, and you select it with /model fable because it is not the default on any plan. It has a 1M token context window and costs more than Opus, and depending on your plan its usage can bill to usage credits.
