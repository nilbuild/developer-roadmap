# Web

Claude Code on the web runs sessions on cloud infrastructure instead of your machine. You start one at [claude.ai/code](http://claude.ai/code), from the Code tab in the Claude app, from the Desktop app, or from the terminal with `claude --cloud`. The session keeps running after you close your laptop, and you can check on it or steer it from any device. Each session clones your GitHub repository into a cloud environment that controls network access, environment variables and setup scripts, and cloud sessions are available on Pro, Max, Team and Enterprise plans.
