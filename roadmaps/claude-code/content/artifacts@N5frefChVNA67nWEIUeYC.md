# Artifacts

Artifacts turn Claude Code's work into live web pages hosted on [claude.ai](http://claude.ai). When terminal text is the wrong medium, such as an annotated pull request, a dashboard or a set of design options, Claude writes an HTML or Markdown page and publishes it to a private URL. The page updates in place when Claude republishes, and you share it from the page header with specific people, your organization or a public link. Pages can pull live data through your MCP connectors, and `/artifacts` lists the ones you own. They need a [claude.ai](http://claude.ai) login and are not available through Amazon Bedrock, Google Cloud's Agent Platform or Microsoft Foundry.

Visit the following resources to learn more:

- [@official@Share session output as artifacts](https://code.claude.com/docs/en/artifacts)
- [@official@Prompt library](https://code.claude.com/docs/en/prompt-library)
