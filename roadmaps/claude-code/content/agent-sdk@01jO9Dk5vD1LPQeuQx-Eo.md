# Agent SDK

The Agent SDK gives you the same tools, agent loop and context management that power Claude Code, as a library for Python and TypeScript. You use it to embed an agent in your own application, with built-in tools for reading files, running commands and searching the web. It also includes hooks, subagents, MCP, permissions and sessions, and it loads skills and [CLAUDE.md](http://CLAUDE.md) files from your project. Authentication uses an API key, and the SDK was previously called the Claude Code SDK.
