# Claude vs Codex vs Cursor

Claude Code, Cursor and Codex are all coding agents that read a repository, edit files and run commands, but they come from different places. Claude Code is Anthropic's agent for Claude models. Cursor is an editor-first product that lets you choose models from several providers, including its own Composer models, and Codex is OpenAI's agent for OpenAI models.
