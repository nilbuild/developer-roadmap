# /schedule

`/schedule` creates and manages cloud scheduled tasks, formerly called routines, from inside a session. Claude asks about the schedule, repositories and prompt, then saves the task to your account. You can pass a description directly, such as `/schedule daily PR review at 9am`, or a one-off like `/schedule in 2 weeks, open a cleanup PR`. `/schedule list`, `update` and `run` manage tasks you already have, and `/routines` is an alias. The command needs a [claude.ai](http://claude.ai) subscription login and a plan that includes cloud sessions.
