# Remote Control

Remote Control connects [claude.ai/code](http://claude.ai/code) or the Claude mobile app to a Claude Code session running on your own machine. Claude keeps running locally, so your filesystem, MCP servers and project configuration stay available while you drive the session from a phone, tablet or another browser. You start it with `claude remote-control`, with `/remote-control` in an open session, or with the `--remote-control` flag. The conversation stays in sync across every connected device, and you can send photos and files from the app.
