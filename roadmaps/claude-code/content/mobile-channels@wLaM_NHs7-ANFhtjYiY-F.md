# Mobile

Claude Code on mobile lets you start and follow coding sessions from your phone. Cloud sessions run on Anthropic infrastructure, and Remote Control lets you continue a session running on your own computer from the phone or tablet. This makes it possible to check progress, answer a permission prompt, or send a new task while you are away from your desk.

Visit the following resources to learn more:

- [@official@Claude Code on mobile](https://code.claude.com/docs/en/mobile)
- [@official@Continue local sessions from any device with Remote Control](https://code.claude.com/docs/en/remote-control)
