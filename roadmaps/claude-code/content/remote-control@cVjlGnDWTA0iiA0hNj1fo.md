# /remote-control

`/remote-control` makes the current session available through Remote Control, so you can continue it from [claude.ai/code](http://claude.ai/code) or the Claude mobile app. Claude keeps running on your machine, so your filesystem, MCP servers and project configuration stay available. You can also start it from the shell with `claude remote-control`. It requires a [claude.ai](http://claude.ai) subscription.

Visit the following resources to learn more:

- [@official@Remote Control](https://code.claude.com/docs/en/remote-control)
