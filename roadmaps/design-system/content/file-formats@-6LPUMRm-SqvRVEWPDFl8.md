# Logo File Formats

Logo file formats determine how a brand mark is encoded, stored, and rendered across different digital and print environments. Vector formats, such as SVG, EPS, and AI, use mathematical paths to ensure the logo remains crisp and scalable at any size without losing quality. Raster formats, including PNG, JPG, and WebP, use a grid of pixels, making them suitable for specific web displays where fixed resolution is preferred. Choosing the correct format ensures that a logo maintains its visual integrity and performance efficiency when implemented throughout a design system.
