# User Onboarding

User onboarding encompasses the design patterns and instructional elements that guide new users through an interface to help them understand its core value and functionality. These guidelines define how tooltips, walkthroughs, empty state illustrations, and progress indicators should look and behave to ensure a consistent experience across the product. By establishing clear standards for welcoming users, teams create intuitive pathways that reduce friction and improve product adoption.
