# From Existing Design

Building from existing design means creating a design system by auditing and standardizing the UI of a product that already exists. This path starts with analyzing current screens, identifying inconsistencies, and extracting reusable patterns before formalizing them into tokens and components. It takes longer upfront than starting from scratch, since the team must reconcile years of inconsistent decisions first.
