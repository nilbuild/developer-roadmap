# Design Tokens

Defining design tokens means translating the visual decisions from a brand's design language into named, reusable values for colors, spacing, typography, and iconography. This step turns abstract design language into concrete variables that both design tools and code can reference directly. Once tokens are defined, components get built by referencing them rather than hardcoding values.
