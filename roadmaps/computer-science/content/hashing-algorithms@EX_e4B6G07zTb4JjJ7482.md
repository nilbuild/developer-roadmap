# Hashing Algorithms

Hashing algorithms map an input of any size to a fixed-size value called a hash. Since there are far more possible inputs than hash values, two different inputs can produce the same hash, which is called a collision; a good cryptographic hashing algorithm makes collisions hard to find. Hashing algorithms are used to verify the integrity of data, to store passwords, and to generate unique identifiers for data.
