# Bellman Ford's Algorithm

Bellman-Ford's algorithm is a graph algorithm that finds the shortest path from a source vertex to all other vertices in a graph. It is a dynamic programming algorithm that uses a bottom-up approach to find the shortest path. It is similar to Dijkstra's algorithm but it can handle negative weights. Floyd-Warshall's algorithm can handle negative weights as well, but it finds the shortest paths between all pairs of vertices in O(V³) time, while Bellman-Ford's algorithm finds them from a single source in O(V·E) time.
