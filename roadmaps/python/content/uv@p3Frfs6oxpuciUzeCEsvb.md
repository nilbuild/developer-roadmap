# uv

uv is an extremely fast Python package installer and resolver designed as a drop-in replacement for pip and pip-tools. It uses a high-performance architecture written in Rust to manage project dependencies, virtual environments, and tool chains, significantly reducing the time required for environment setup and package synchronization.
