# AGENTS.md

`AGENTS.md` is a markdown file with persistent instructions for Codex. A global file lives in your Codex home folder, and project files live from the repository root down to your working directory. An `AGENTS.override.md` in the same folder takes precedence over `AGENTS.md`. Codex stops reading once the combined size reaches 32 KiB by default, so keep the files short and split detail into nested folders.
