# Fix Bugs & Refactoring

For bug fixes, give Codex the error message, the steps to reproduce it and the expected behavior. It can find the cause, apply a fix and run the tests to confirm. For refactoring, state what must stay the same and what the target structure is, and ask it to keep the test suite passing. Review each change in the diff before accepting it.
