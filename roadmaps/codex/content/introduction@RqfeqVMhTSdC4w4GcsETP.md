# Introduction

Codex is OpenAI's coding agent. It reads your codebase, edits files, runs commands and tests, and reports what it changed. You can use it from the terminal with the open-source Codex CLI, in the ChatGPT desktop app, in your editor, on the web and from your phone. All of these surfaces share the same agent and much of the same configuration.
