# Review Diffs

Reviewing the diff is how you stay in control of what Codex changed. The desktop app and IDE extension show a focused diff you can inspect in place, and in the CLI `/diff` shows all edits, including new files. You can also have a separate reviewer check them with `/review`, or run `codex review` on uncommitted changes, a branch or a commit. Read the changes yourself before you commit.

Visit the following resources to learn more:

- [@official@Code review](https://learn.chatgpt.com/docs/code-review)
