# Review Diffs

Reviewing the diff is how you stay in control of what Codex changed. Use `/diff` to see all edits, including new files, and `/review` to have a separate reviewer check them. You can also run `codex review` from the command line on uncommitted changes, a branch or a commit. Read the changes yourself before you commit.

Visit the following resources to learn more:

- [@official@Code review](https://learn.chatgpt.com/docs/code-review)
