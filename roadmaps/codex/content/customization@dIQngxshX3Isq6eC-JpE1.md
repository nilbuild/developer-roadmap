# Customization

Customization lets you extend Codex beyond its built-in behavior. Skills package repeatable workflows, MCP connects external tools and data, plugins bundle both for sharing, and `config.toml` holds your settings. Start with `AGENTS.md` and a few skills, and add integrations only when you need them.

Visit the following resources to learn more:

- [@official@Codex configuration](https://learn.chatgpt.com/docs/configuration)
