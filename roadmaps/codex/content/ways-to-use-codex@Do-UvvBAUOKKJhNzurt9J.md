# Ways to use Codex

Codex runs on several surfaces that share the same agent. The CLI works in your terminal, the ChatGPT desktop app manages many projects at once, and editor extensions bring it beside your code. The web and mobile apps let you start and follow tasks from anywhere, and Codex Cloud runs tasks on remote infrastructure. Pick the surface that fits where you work, and move between them when needed.
