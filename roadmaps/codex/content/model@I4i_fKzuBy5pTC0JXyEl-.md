# /model

`/model` chooses the active model and, when the model supports it, the reasoning effort. Use it to move to a stronger model for a hard task or a cheaper one for simple work. The change applies to the current session.

Visit the following resources to learn more:

- [@official@Models](https://learn.chatgpt.com/docs/models)
- [@official@Model selection](https://learn.chatgpt.com/docs/model-selection)
