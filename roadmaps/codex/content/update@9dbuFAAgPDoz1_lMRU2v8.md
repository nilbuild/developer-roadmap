# update

`codex update` checks for a newer Codex CLI version and applies it when your install supports self-update. If you installed with npm or Homebrew, you can also update through that package manager. Keeping the CLI current matters because newer models can require a minimum version.

Visit the following resources to learn more:

- [@official@codex update](https://learn.chatgpt.com/docs/developer-commands?surface=cli#cli-codex-update)
- [@official@Models](https://learn.chatgpt.com/docs/models)
