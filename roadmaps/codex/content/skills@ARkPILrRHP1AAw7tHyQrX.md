# Skills

A skill is a folder with a `SKILL.md` file that teaches Codex a repeatable workflow. The file needs a `name` and a `description`, and it can include scripts, references and assets. Codex loads only the name and description at first, and reads the full file when the skill is selected or the task matches. You call one explicitly with `$skill-name` or `/skills`. Skills are found in `.agents/skills` in your repository, in your home folder, and in an admin location.
