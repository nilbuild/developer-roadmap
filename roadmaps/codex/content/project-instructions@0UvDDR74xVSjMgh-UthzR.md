# Project Instructions

Project instructions give Codex standing guidance so you do not repeat yourself in every prompt. They live in `AGENTS.md` files that Codex reads at the start of a run. Use them for how to build and test, the conventions to follow and the rules specific to a folder. Codex combines files from the project root down to your current directory, with nearer files taking precedence.

Visit the following resources to learn more:

- [@official@AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
