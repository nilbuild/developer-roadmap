# @

Typing `@` opens a fuzzy file search in the composer. Choosing a result inserts that file path into your prompt, so Codex looks at exactly the file you mean. The `/mention` command does the same for files and folders.

Visit the following resources to learn more:

- [@official@CLI interactive shortcuts](https://learn.chatgpt.com/docs/developer-commands?surface=cli#cli-interactive-shortcuts)
