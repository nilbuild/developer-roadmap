# Scaling Codex

Scaling Codex means running more work at once without the tasks colliding. You can use Git worktrees to give each task its own checkout, run several sessions in parallel, and delegate focused work to subagents. Parallel work is safest when each task writes to different files. Cloud tasks add another way to run work without using your machine.
