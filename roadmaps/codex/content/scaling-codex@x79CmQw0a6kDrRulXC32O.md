# Scaling Codex

Scaling Codex means running more work at once without the tasks colliding. The desktop app lets you run several projects and chats in parallel, Git worktrees give each task its own checkout, and subagents handle focused pieces inside a task. Cloud tasks add another way to run work without using your machine. Parallel work is safest when each task writes to different files.
