# Resuming

Resuming reopens a saved chat with its context, so you can continue across days without explaining the task again. In the desktop and mobile apps you open the existing chat. In the CLI, use `codex resume` to pick one, `codex resume --last` for the most recent, or `/resume` inside the terminal UI.

Visit the following resources to learn more:

- [@official@Developer commands](https://learn.chatgpt.com/docs/developer-commands)
