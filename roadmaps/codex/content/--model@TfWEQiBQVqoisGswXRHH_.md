# --model

`--model` (or `-m`) overrides the configured model for one run, for example `codex -m gpt-6.1-sol`. The same setting can be made permanent with `model` in `config.toml`. Inside a session, `/model` changes it without restarting.

Visit the following resources to learn more:

- [@official@Models](https://learn.chatgpt.com/docs/models)
