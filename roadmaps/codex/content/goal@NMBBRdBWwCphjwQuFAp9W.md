# /goal

`/goal` sets, edits, pauses, resumes, shows or clears a task goal. The goal text works as both the first prompt and the completion criteria, so Codex keeps working until the outcome is reached. It is available in the desktop app, the CLI and the IDE extension, and the desktop app shows a progress row you can pause, resume, edit or clear. A good goal states the result, the constraints and how to verify it, and it keeps the same sandbox and approval settings.
