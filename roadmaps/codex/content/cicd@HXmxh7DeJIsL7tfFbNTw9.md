# CI/CD

Codex can run inside your CI/CD pipeline to review pull requests, apply patches or generate reports. The usual building blocks are `codex exec` for the non-interactive run and the official GitHub Action. Authenticate with an API key stored as a secret, keep the sandbox as strict as the job allows, and treat pull request text as untrusted input.

Visit the following resources to learn more:

- [@official@Non-interactive mode](https://learn.chatgpt.com/docs/non-interactive-mode)
- [@official@Codex GitHub Action](https://learn.chatgpt.com/docs/github-action)
