# Initialize a Project

Initializing a project means creating its first `AGENTS.md`. Run `/init` in the project directory and Codex generates a scaffold you can edit. Review it, remove anything generic, and add the real build commands and rules of your repository.

Visit the following resources to learn more:

- [@official@AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
- [@official@CLI commands and flags](https://learn.chatgpt.com/docs/developer-commands?surface=cli)
