# Subscription Plans

Codex is included with ChatGPT Free, Go, Plus, Pro, Business, Edu and Enterprise plans. Higher plans give more usage and add cloud features such as automatic code review and Slack. Usage is measured in estimated messages per five-hour window for each model, and Pro currently has no five-hour limit. When you reach the included limits, Plus and Pro users can buy credits.
