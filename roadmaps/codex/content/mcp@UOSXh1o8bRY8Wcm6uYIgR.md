# /mcp

`/mcp` lists the MCP tools configured for the session, and adding `verbose` shows server details. Use it to check which external tools Codex can call. It works in the CLI and the desktop app composer, and servers themselves are added with `codex mcp add` or in `config.toml`.

Visit the following resources to learn more:

- [@official@MCP in Codex](https://learn.chatgpt.com/docs/extend/mcp)
