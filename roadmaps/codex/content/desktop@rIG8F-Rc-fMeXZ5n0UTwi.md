# Desktop

The ChatGPT desktop app is a graphical home for Codex on macOS, Windows and Linux. It lets you run several projects in parallel, keeps every chat visible and supports scheduled tasks, worktrees, browser use and computer use. You can start it from the terminal with `codex app`, or continue a CLI session in it with `/app`.

Visit the following resources to learn more:

- [@official@ChatGPT desktop app](https://learn.chatgpt.com/docs/app)
- [@official@Quickstart](https://learn.chatgpt.com/docs/quickstart)
