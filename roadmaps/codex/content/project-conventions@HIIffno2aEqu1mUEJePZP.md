# Project Conventions

Project conventions are the rules Codex should follow when it works in your repository. Typical entries are how to run tests and linters, naming and formatting rules, folders that should not be edited, and what a good pull request looks like. Add a rule when you notice Codex repeating the same mistake. Put folder-specific rules in a nested `AGENTS.md` close to the code.

Visit the following resources to learn more:

- [@official@AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
