# /plugins

`/plugins` lists installed and discoverable plugins. From there you can inspect a plugin's tools, install one from a configured marketplace, or turn it on or off. Start a new session after installing before you use the plugin's skills or tools.

Visit the following resources to learn more:

- [@official@CLI built-in slash commands](https://learn.chatgpt.com/docs/developer-commands?surface=cli#cli-built-in-slash-commands)
- [@official@Plugins](https://learn.chatgpt.com/docs/plugins)
