# Codex Models

Codex works with the GPT-6 model family, and each model suits a different kind of work. Astra is the most capable, Sol handles long-running work at a lower cost, Terra is fast with strong visual understanding and computer use, and Luna is the most efficient for high-volume tasks. You pick one with `/model`, the `--model` flag, or `model` in `config.toml`. Model names and retirements change often, so check the models page for the current list.

Visit the following resources to learn more:

- [@official@Models](https://learn.chatgpt.com/docs/models)
- [@official@Model selection](https://learn.chatgpt.com/docs/model-selection)
