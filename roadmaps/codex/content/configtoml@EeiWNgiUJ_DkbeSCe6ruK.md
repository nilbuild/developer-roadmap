# config.toml

`config.toml` is Codex's main settings file, found at `~/.codex/config.toml`. A trusted project can add its own `.codex/config.toml` for project-specific settings. It holds the model, sandbox mode, approval policy, MCP servers, hooks and many other options. The CLI, desktop app and IDE extension share it, and `--config` overrides a value for one run.
