# Slash Commands (/)

Typing `/` in the composer opens the list of built-in slash commands. They control the session from inside the terminal UI: choosing a model, changing permissions, planning, reviewing, managing context and more. Type part of a name to filter the list, then press Enter to run it.

Visit the following resources to learn more:

- [@official@Slash commands](https://learn.chatgpt.com/docs/developer-commands?surface=cli)
