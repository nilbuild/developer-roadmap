# Slash Commands (/)

Typing `/` in the composer opens the list of built-in slash commands. They control the session from inside the chat: choosing a model, changing permissions, planning, reviewing, managing context and more. The CLI has the full set, and the desktop app composer supports a subset such as `/goal`, `/init`, `/mcp`, `/plan`, `/review` and `/status`. Type part of a name to filter the list, then press Enter to run it.
