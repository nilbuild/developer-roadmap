# Codex cloud

Codex Cloud runs coding tasks on remote infrastructure instead of your machine. You create an environment with your repositories, setup scripts, internet access rules and secrets, then send a task to it. Each task gets its own workspace and keeps running while your computer sleeps. You review the changed files and test results, then commit or open a pull request, or apply the diff locally with `codex apply`.

Visit the following resources to learn more:

- [@official@Codex Cloud](https://learn.chatgpt.com/docs/cloud)
- [@official@Cloud environments](https://learn.chatgpt.com/docs/environments/cloud-environments)
