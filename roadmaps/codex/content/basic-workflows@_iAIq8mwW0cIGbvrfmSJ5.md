# Basic Workflows

Most Codex work follows a few repeatable patterns: exploring a codebase, writing a good prompt, planning before editing, fixing bugs and reviewing the diff. Each pattern works the same in the CLI, the app and the IDE. Start with the one that matches your task, and use `/plan` and `/review` to add structure.

Visit the following resources to learn more:

- [@official@Prompting](https://learn.chatgpt.com/docs/prompting)
- [@official@Codex CLI](https://learn.chatgpt.com/docs/cli)
