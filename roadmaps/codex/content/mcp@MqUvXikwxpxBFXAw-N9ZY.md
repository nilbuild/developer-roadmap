# mcp

`codex mcp` manages MCP servers from the command line. The subcommands `add`, `get`, `list`, `login`, `logout` and `remove` cover the whole lifecycle, including OAuth sign-in for remote servers. Servers are saved in `config.toml`, so the CLI, desktop app and IDE extension share them.
