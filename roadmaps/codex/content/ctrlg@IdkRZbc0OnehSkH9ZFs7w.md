# Ctrl+G

`Ctrl+G` opens the current prompt in your external editor, as set by the `$VISUAL` or `$EDITOR` environment variable. This is useful for writing long, multi-line prompts with your usual editing tools. When you save and close the editor, the text returns to the composer.
