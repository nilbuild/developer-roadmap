# /mention

`/mention` attaches a file or folder to the chat. Codex then looks at exactly what you point to instead of searching for it. Typing `@` in the composer gives the same result with file search.

Visit the following resources to learn more:

- [@official@CLI built-in slash commands](https://learn.chatgpt.com/docs/developer-commands?surface=cli#cli-built-in-slash-commands)
