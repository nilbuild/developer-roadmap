# /review

`/review` asks Codex to review your working tree. A dedicated reviewer reads the selected diff, such as uncommitted changes or a branch against its base, and reports prioritized findings without editing files. You can set `review_model` in `config.toml` to use a different model for reviews.

Visit the following resources to learn more:

- [@official@Code review](https://learn.chatgpt.com/docs/code-review)
