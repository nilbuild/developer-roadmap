# Sol

GPT-6.2 Sol (`gpt-6.2-sol`) is built for everyday coding, writing and multi-step work, such as reviewing a pull request, revising code after review, or turning meeting notes into a project brief. The docs say it completes more tasks on the same paid plan than GPT-6.1 Sol. It is also the model the subagent docs suggest for demanding work, and it supports Ultrafast mode on eligible plans.
