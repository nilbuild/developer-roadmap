# Sol

GPT-6.1 Sol (`gpt-6.1-sol`) is built for repeated, long-running work across code, apps and documents. The docs describe its performance as close to Astra at a lower cost. It is the model the subagent docs suggest for demanding work, and it gets Ultrafast mode on eligible plans.
