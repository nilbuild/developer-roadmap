# Usage Limits

Included usage is measured in estimated messages per five-hour window for each model, and the numbers differ between Astra, Sol, Terra and Luna. Pro currently has no five-hour limit, and cloud tasks can use more allowance than local messages. When you run out, Plus and Pro users can buy credits. Check `/usage` and the usage dashboard for current figures, since the limits are estimates.
