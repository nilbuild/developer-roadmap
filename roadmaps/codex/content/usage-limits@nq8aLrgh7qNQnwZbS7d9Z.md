# Usage Limits

Included usage is measured in estimated messages per five-hour window for each model, and the numbers differ between Astra, Sol, Terra and Luna. Usage counts across the desktop app, CLI, IDE extension and web, and cloud tasks can use more allowance than local messages. Pro currently has no five-hour limit, and Plus and Pro users can buy credits when they run out. Check the usage dashboard, or `/usage` in the CLI, for current figures, since the limits are estimates.
