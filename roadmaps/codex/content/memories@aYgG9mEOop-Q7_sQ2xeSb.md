# /memories

`/memories` configures how Codex uses and generates memory. You can turn memory injection or memory generation on or off without leaving the terminal UI. Memories are information Codex keeps across sessions, in addition to the instructions you write in `AGENTS.md`.

Visit the following resources to learn more:

- [@official@Slash commands](https://learn.chatgpt.com/docs/developer-commands?surface=cli)
