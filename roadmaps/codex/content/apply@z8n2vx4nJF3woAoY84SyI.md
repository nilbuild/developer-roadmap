# apply

`codex apply` applies the latest diff from a Codex Cloud task to your local working tree. You pass the task ID, and the command is also available as `codex a`. Use it to bring cloud results into your local checkout after you have reviewed them.

Visit the following resources to learn more:

- [@official@Codex Cloud](https://learn.chatgpt.com/docs/cloud)
- [@official@CLI commands and flags](https://learn.chatgpt.com/docs/developer-commands?surface=cli)
