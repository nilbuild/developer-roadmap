# /init

`/init` generates an `AGENTS.md` scaffold in the current directory. The file gives Codex persistent instructions for the project, such as build and test commands and coding conventions. Run it once in a new repository, then edit the result.

Visit the following resources to learn more:

- [@official@CLI built-in slash commands](https://learn.chatgpt.com/docs/developer-commands?surface=cli#cli-built-in-slash-commands)
- [@official@AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
