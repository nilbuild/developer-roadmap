# !

Starting a prompt with `!` runs the rest as a local shell command instead of sending it to the model. The command runs under your current approval and sandbox settings. Use it for quick checks, such as `!git status`, without leaving Codex.

Visit the following resources to learn more:

- [@official@CLI interactive shortcuts](https://learn.chatgpt.com/docs/developer-commands?surface=cli#cli-interactive-shortcuts)
