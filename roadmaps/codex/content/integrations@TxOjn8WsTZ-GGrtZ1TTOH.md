# Integrations

Codex connects to the tools where your team already works. On GitHub it can review pull requests automatically and respond to `@codex` mentions, and it can also start tasks from issues. It also works in GitLab (beta), Slack and Linear, where you can assign or mention Codex on an issue. Most of these integrations run in the cloud and need a ChatGPT plan rather than an API key.

Visit the following resources to learn more:

- [@official@GitHub integration](https://developers.openai.com/codex/integrations/github)
- [@official@Use Codex in Linear](https://learn.chatgpt.com/docs/third-party/linear)
- [@official@Codex Cloud](https://learn.chatgpt.com/docs/cloud)
