# Editor Extensions

The Codex IDE extension works beside your code in the editor. It can use your open files, selected code and recent chats as context, and you review its edits in place. It supports VS Code, Cursor, Windsurf and VS Code Insiders, while Xcode and JetBrains IDEs have their own integrations. Plugins are not available in the extension.
