# login

`codex login` signs you in. It supports ChatGPT OAuth, device auth for remote or headless machines with `--device-auth`, an API key piped in with `--with-api-key`, and an access token with `--with-access-token`. `codex login status` shows the active auth mode and exits with code 0 when you are logged in.

Visit the following resources to learn more:

- [@official@CLI commands and flags](https://learn.chatgpt.com/docs/developer-commands?surface=cli)
