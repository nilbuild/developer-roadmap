# Code Review

Codex can review code at several points. `/review` and `codex review` check local changes, such as uncommitted work, a branch against its base or a single commit, and report findings without editing files. On GitHub, Codex can review pull requests automatically, and you can also request a review by commenting `@codex review`. The same cloud review works for GitLab merge requests.
