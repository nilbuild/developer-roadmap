# Code Review

Codex can review code at several points. In the desktop app and IDE extension you choose to review against a base branch or review uncommitted changes, and in the CLI `/review` and `codex review` do the same without editing files. On GitHub, Codex can review pull requests automatically, and you can also request a review by commenting `@codex review`. The same cloud review works for GitLab merge requests.

Visit the following resources to learn more:

- [@official@Code review](https://learn.chatgpt.com/docs/code-review)
- [@official@GitHub integration](https://developers.openai.com/codex/integrations/github)
