# Using Codex

Using Codex means giving it a task, watching it work and reviewing the result. You describe the outcome, Codex explores the code, makes changes and runs checks, and you approve or redirect it along the way. The same loop applies in the terminal, the desktop app and your editor. Permissions and the sandbox decide how much Codex can do before it asks.

Visit the following resources to learn more:

- [@official@Prompting](https://learn.chatgpt.com/docs/prompting)
