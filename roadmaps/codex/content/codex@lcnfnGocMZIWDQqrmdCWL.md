# codex

`codex` starts the interactive terminal UI in the current directory. You can pass an optional starting prompt, for example `codex "explain this project"`, and attach images with `--image`. Run it from the root of the project you want to work on, because Codex uses the working directory as its workspace.

Visit the following resources to learn more:

- [@official@Codex CLI](https://learn.chatgpt.com/docs/cli)
- [@official@CLI commands and flags](https://learn.chatgpt.com/docs/developer-commands?surface=cli)
