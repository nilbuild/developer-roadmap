# Plugins

A plugin is an installable bundle of capabilities. It can include skills, MCP server connections, hooks and browser extensions, and it is distributed through a directory shared by ChatGPT and Codex. In the desktop app you add plugins from the Plugins tab, and in the CLI you use `/plugins` or `codex plugin` to install from a configured marketplace. Plugins are not available in the IDE extension, and a new chat or session is needed after installing so the plugin's skills and tools load.

Visit the following resources to learn more:

- [@official@Plugins](https://learn.chatgpt.com/docs/plugins)
