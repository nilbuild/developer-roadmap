# Plugins

A plugin is an installable bundle of capabilities. It can include skills, MCP server connections, hooks and browser extensions, and it is distributed through a marketplace shared by ChatGPT and Codex. In the CLI you open `/plugins` or use `codex plugin` to install from a configured marketplace. Start a new session after installing so the plugin's skills and tools load.

Visit the following resources to learn more:

- [@official@Plugins](https://learn.chatgpt.com/docs/plugins)
