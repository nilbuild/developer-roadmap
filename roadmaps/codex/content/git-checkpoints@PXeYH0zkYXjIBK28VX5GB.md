# Git Checkpoints

A Git checkpoint is a commit or stash you make before and after a Codex task. The docs recommend creating them in the CLI and the IDE extension so you can revert if the changes go wrong. Codex edits real files in your working tree, so a clean starting point makes review and rollback simple. Worktrees give a stronger form of isolation for bigger tasks, and the desktop app can run a task in one.

Visit the following resources to learn more:

- [@official@Codex CLI](https://learn.chatgpt.com/docs/cli)
- [@official@Codex IDE extension](https://learn.chatgpt.com/docs/ide)
