# Git Checkpoints

A Git checkpoint is a commit or stash you make before and after a Codex task. The docs recommend creating them so you can revert if the changes go wrong. Codex edits real files in your working tree, so a clean starting point makes review and rollback simple. Worktrees give a stronger form of isolation for bigger tasks.
