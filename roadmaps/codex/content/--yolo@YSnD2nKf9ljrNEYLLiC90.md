# --yolo

`--yolo` is the short form of `--dangerously-bypass-approvals-and-sandbox`. It runs every command without approvals and without a sandbox, so Codex can change anything your user account can. Use it only inside an environment that is already isolated, such as a disposable container. For fewer prompts with more safety, use `--approve-for-me` instead.

Visit the following resources to learn more:

- [@official@Sandboxing and approvals](https://learn.chatgpt.com/docs/sandboxing)
