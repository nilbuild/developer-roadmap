# Git Worktrees

A Git worktree is a second checkout of the same repository, so each task gets its own files and branch. Codex can create one for you: start with `codex --worktree`, use `/worktree` in a session, or run a scheduled task in a background worktree. This keeps parallel tasks from overwriting each other and keeps experiments away from your unfinished work.
