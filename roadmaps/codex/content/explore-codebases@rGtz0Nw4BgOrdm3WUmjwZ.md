# Explore Codebases

Codex can read a repository and explain how it is organized before you change anything. Ask it for an overview, to trace where a feature is implemented, or to list the files involved in a bug. This is read-only work, so it is a safe way to start in an unfamiliar project. Use a read-only sandbox if you want to be sure nothing changes.
