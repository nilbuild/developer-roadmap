# review

`codex review` runs a non-interactive code review. You can point it at uncommitted changes with `--uncommitted`, at a branch diff with `--base`, or at a single commit with `--commit`, and you can add custom review instructions. Codex reports prioritized findings and does not change your working tree.

Visit the following resources to learn more:

- [@official@Code review](https://learn.chatgpt.com/docs/code-review)
- [@official@CLI commands and flags](https://learn.chatgpt.com/docs/developer-commands?surface=cli)
