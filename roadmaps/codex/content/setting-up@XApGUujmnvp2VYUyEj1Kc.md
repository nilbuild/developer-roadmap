# Setting Up

Setting up Codex depends on where you want to use it. The ChatGPT desktop app installs on macOS, Windows and Linux, and the web version only needs a ChatGPT account at chatgpt.com. For the terminal, install the CLI with the install script, `npm install -g @openai/codex` or `brew install --cask codex`, and for your editor, install or enable the Codex IDE extension. In every case you sign in with your ChatGPT account, and an API key is available as an alternative with fewer features.

Visit the following resources to learn more:

- [@official@Codex CLI](https://learn.chatgpt.com/docs/cli)
- [@opensource@Codex CLI on GitHub](https://github.com/openai/codex)
- [@official@Quickstart](https://learn.chatgpt.com/docs/quickstart)
- [@official@Codex IDE extension](https://learn.chatgpt.com/docs/ide)
- [@official@ChatGPT desktop app](https://learn.chatgpt.com/docs/app)
