# Setting Up

To set up the Codex CLI, install it, run `codex` in a project folder and sign in. On macOS and Linux the install script is `curl -fsSL https://chatgpt.com/codex/install.sh | sh`, and a PowerShell script exists for Windows. You can also install with `npm install -g @openai/codex` or `brew install --cask codex`. When Codex starts for the first time, choose "Sign in with ChatGPT" or use an API key.

Visit the following resources to learn more:

- [@official@Codex CLI](https://learn.chatgpt.com/docs/cli)
- [@opensource@Codex CLI on GitHub](https://github.com/openai/codex)
