# What is a Coding Agent?

A coding agent is an AI system that can write, test and debug code on its own to complete a task. Unlike autocomplete, it can read many files, run shell commands, see the results and decide what to do next. You describe the outcome, and the agent plans and carries out the steps while you review the work.
