# Luna

GPT-6 Luna (`gpt-6-luna`) is the most cost-efficient model, meant for focused, high-volume tasks such as summarization, extraction and narrow coding jobs. It has by far the largest usage allowance. The docs suggest it for fast, narrow subagent tasks.
