# Your First Task

A good first task is small and easy to check, such as asking Codex to explain the project or fix a failing test. Open a project folder, run `codex`, and give a clear prompt with the goal and how to verify it. Review the changes with `/diff`, and run the tests yourself or ask Codex to run them. Create Git checkpoints before and after the task so you can revert if needed.

Visit the following resources to learn more:

- [@official@Codex CLI](https://learn.chatgpt.com/docs/cli)
- [@official@Quickstart](https://learn.chatgpt.com/docs/quickstart)
