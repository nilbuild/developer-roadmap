# Your First Task

A good first task is small and easy to check, such as asking Codex to explain a project or fix a failing test. Open a project folder in the desktop app, your editor or the terminal, and describe the goal and how to verify it. Review the changes in the diff, then run the tests yourself or ask Codex to run them. Create Git checkpoints before and after the task so you can revert if needed.
