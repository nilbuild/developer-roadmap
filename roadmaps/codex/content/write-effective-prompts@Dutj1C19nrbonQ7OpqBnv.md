# Write Effective Prompts

An effective prompt states the goal, gives the context, names the constraints and says how to check the result. For code, that means reproduction steps, the files that matter, boundaries such as what not to change, and a test or command that proves it works. Short prompts are fine when the task is clear. You can steer a running task with follow-up messages.
