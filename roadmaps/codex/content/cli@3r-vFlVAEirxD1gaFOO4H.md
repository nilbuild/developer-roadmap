# CLI

The Codex CLI is a coding agent that runs locally in your terminal. You start it with `codex` inside a project, describe a task, and Codex inspects the code, edits files and runs your tools. It also supports sessions, code review, non-interactive runs with `codex exec`, skills, MCP servers and subagents. The CLI is open source under the Apache-2.0 license.

Visit the following resources to learn more:

- [@official@Codex CLI](https://learn.chatgpt.com/docs/cli)
