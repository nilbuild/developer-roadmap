# What is Agentic Loop?

An agentic loop is the cycle an agent repeats until a task is done. The model reasons over the current context, calls a tool such as reading a file or running a command, observes the result and decides on the next step. In Codex this loop is bounded by the sandbox and approval settings, so the agent pauses when it needs permission to go further.
