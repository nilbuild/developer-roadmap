# /subagents

`/subagents` switches the active subagent thread. When Codex spawns subagents, each one works in its own thread, and this command lets you inspect or continue one from the main session. The `/agents` command opens a broader view for browsing chats and agents.

Visit the following resources to learn more:

- [@official@CLI built-in slash commands](https://learn.chatgpt.com/docs/developer-commands?surface=cli#cli-built-in-slash-commands)
- [@official@Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents)
