# --image

`--image` (or `-i`) attaches one or more images to the first prompt. Separate several paths with commas or repeat the flag. It is useful for error screenshots, design mockups and diagrams, as in `codex -i screenshot.png "Explain this error"`.

Visit the following resources to learn more:

- [@official@Image inputs](https://learn.chatgpt.com/docs/image-inputs)
