# /plan

`/plan` switches Codex to plan mode, optionally with a prompt. Codex proposes an approach before it changes anything, so you can correct the direction first. For long tasks, plan first and then turn the result into a goal with `/goal`.

Visit the following resources to learn more:

- [@official@Prompting](https://learn.chatgpt.com/docs/prompting)
- [@official@Long-running work](https://learn.chatgpt.com/docs/long-running-work)
