# API usage

You can sign in to Codex with an OpenAI API key instead of a ChatGPT account. API usage is billed at standard API rates and follows the models available to your key. Cloud features such as GitHub code review and Slack are not available with an API key. API keys are also the recommended way to authenticate Codex in CI.

Visit the following resources to learn more:

- [@official@Codex pricing](https://learn.chatgpt.com/docs/pricing)
- [@official@Non-interactive mode](https://learn.chatgpt.com/docs/non-interactive-mode)
