# /fast

`/fast` toggles the Fast service tier for models that offer one. Fast mode returns results sooner but uses more credits, so it fits work you are waiting on. The setting persists until you switch it off.

Visit the following resources to learn more:

- [@official@CLI built-in slash commands](https://learn.chatgpt.com/docs/developer-commands?surface=cli#cli-built-in-slash-commands)
- [@official@Codex pricing](https://learn.chatgpt.com/docs/pricing)
