# Web

Codex on the web runs in your browser at [chatgpt.com](http://chatgpt.com). You sign in with your ChatGPT account, choose where Codex should work and send a task. Web tasks run in the cloud, so they can keep going after you close the page. You can review the results there and continue from other devices.

Visit the following resources to learn more:

- [@official@ChatGPT on the web](https://learn.chatgpt.com/docs/web)
- [@official@Codex Cloud](https://learn.chatgpt.com/docs/cloud)
