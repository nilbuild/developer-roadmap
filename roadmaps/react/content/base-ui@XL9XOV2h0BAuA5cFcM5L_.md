# Base UI

Base UI is an open-source library of unstyled React components for building accessible interfaces and design systems. From the creators of Radix UI, Material UI, and Floating UI, it focuses on accessibility, performance, and developer experience while giving you full control over markup and styling. It is the recommended choice for new projects; Radix Primitives remains a mature, actively maintained alternative.
