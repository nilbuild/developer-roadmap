# Microsoft Clarity

Microsoft Clarity is a free analytics tool that provides heatmaps and session recordings, showing how visitors actually move through and interact with a page, rather than just reporting traffic numbers.

Visit the following resources to learn more:

- [@official@Clarity Overview](https://learn.microsoft.com/en-us/clarity/setup-and-installation/about-clarity)
- [@official@Heatmaps overview](https://learn.microsoft.com/en-us/clarity/heatmaps/heatmaps-overview)
- [@video@Touring Microsoft Clarity Heatmaps](https://www.youtube.com/watch?v=uUmFKG-59zk)
