# Before/After Prompt Tests

Before/after prompt tests run the same set of AI prompts before and after a change to a website. The answers are then compared to see if the change affected how AI systems describe, mention, or cite the brand. The prompts stay fixed, so any difference in the answers can be linked more clearly to the change. Results can vary between runs, so teams often repeat each prompt several times and look at the overall pattern.
