# HTTP & Status Codes

HTTP is the protocol that browsers and crawlers use to request pages from a web server and receive a response. Each response includes a three-digit status code that tells what happened with the request. Codes starting with 2 mean success, 3 mean a redirect, 4 mean a client error such as 404 not found, and 5 mean a server error. Search engines read these codes to decide if a page should be crawled again, indexed, moved to a new URL, or removed.
