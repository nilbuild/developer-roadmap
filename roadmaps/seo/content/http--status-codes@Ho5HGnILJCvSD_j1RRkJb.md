# HTTP & Status Codes

HTTP status codes are three-digit codes a server sends back describing what happened with a request, such as whether a page loaded successfully, moved, or failed to load. Understanding these codes is essential for diagnosing why a page might not be getting crawled, indexed, or displayed correctly.
