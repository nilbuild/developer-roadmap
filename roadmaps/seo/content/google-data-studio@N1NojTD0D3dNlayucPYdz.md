# Google Data Studio

Google Data Studio, now known as Looker Studio, is a free tool for building custom dashboards and reports by pulling data from sources like Google Analytics and Search Console into a single visual interface.

Visit the following resources to learn more:

- [@official@Tutorial: Create a new report](https://support.google.com/looker-studio/answer/6292570)
- [@official@Quick start guide](https://cloud.google.com/looker/docs/studio/quick-start-guide)
- [@video@Search Console Data in Looker Studio - Google](https://www.youtube.com/watch?v=gm3YiEZVOts)
