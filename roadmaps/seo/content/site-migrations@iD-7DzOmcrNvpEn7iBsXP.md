# Site Migrations

A site migration is any major change to a website's structure, domain, or platform, such as moving to a new domain, switching from HTTP to HTTPS, or redesigning the URL structure. Migrations carry significant risk of losing search visibility if not planned and executed carefully, since search engines need to correctly understand that old URLs have moved to new ones.
