# International SEO

International SEO is the work of making a website rank well in search results for users in different countries and languages. It deals with how URLs are structured, for example country domains, subdirectories, or subdomains, and how each language version of a page is marked with hreflang tags. It also covers translated and localized content, so the text fits the culture, currency, and search habits of each market. Search engines use these signals to show the right version of a page to the right user.
