# Sitemaps

A sitemap is a file that lists the pages on a website, helping search engines discover content that might otherwise be missed through normal crawling. It is typically submitted directly to a search engine through tools like Google Search Console. Sitemaps do not guarantee indexing, but they make discovery more reliable, especially on large sites.
