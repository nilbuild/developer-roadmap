# Agentic Search

Agentic search is when an AI system does not just answer a question, but takes actions on a user's behalf, such as browsing multiple pages, comparing options, or completing a task like booking or purchasing. It represents a shift from search as information retrieval toward search as a component of autonomous task completion.
