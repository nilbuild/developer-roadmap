# Robots.txt

Robots.txt is a text file placed at the root of a website that tells crawlers which parts of the site they are allowed or not allowed to visit. It can be used to block specific bots entirely, including AI crawlers, or to keep crawlers away from pages like admin panels or duplicate content. It works on trust, since well-behaved bots follow it but not all crawlers do.
