# GraphQL

GraphQL is Facebook's query language for APIs, allowing clients to request exactly the data they need. Uses a single endpoint with schema-defined data structure, reducing over-fetching and under-fetching. More flexible than REST for complex applications with diverse platform needs. Most servers expose it over HTTP, and the GraphQL over HTTP specification now standardizes the methods, media types and status codes for doing so.
