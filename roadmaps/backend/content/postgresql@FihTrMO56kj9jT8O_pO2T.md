# PostgreSQL

PostgreSQL is an advanced, open-source RDBMS known for robustness, extensibility, and standards compliance. Supports complex queries, custom data types, full-text search, and ACID properties. Highly extensible with strong concurrency support, suitable for web apps to data warehousing. The latest major release is PostgreSQL 19 (November 2026); new versions arrive roughly once a year.
