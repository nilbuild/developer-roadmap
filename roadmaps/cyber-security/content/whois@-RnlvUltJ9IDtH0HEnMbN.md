# WHOIS

WHOIS is a query and response protocol used to look up the registered users or assignees of Internet resources such as domain names, IP address blocks, and autonomous system numbers. Records typically include registrant contact details (often redacted for individuals), creation and expiration dates, the registrar, and nameservers. This data is valuable for identifying sources of abuse, tracking malicious actors, and verifying the legitimacy of online resources. For most generic top-level domains (gTLDs), such as .org, WHOIS has been replaced by RDAP (Registration Data Access Protocol): unlike WHOIS's free-form text, which varies by registry and registrar, it returns standardized JSON responses and supports different levels of access to registration data. The .com, .name and .post domains must still offer WHOIS alongside RDAP, and many country-code TLDs still rely on WHOIS.
