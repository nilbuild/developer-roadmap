# Pytorch

PyTorch is Facebook's open-source deep learning framework known for its dynamic computation graph and Python-first design. It is widely used in game AI research and is increasingly deployed in production game server backends for real-time inference tasks.

Visit the following resources to learn more:

- [@official@Learn the Basics — PyTorch Tutorials](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)
- [@article@Zero to Mastery Learn PyTorch for Deep Learning](https://www.learnpytorch.io/)
- [@article@Introduction to PyTorch — UvA DL Notebooks](https://uvadlc-notebooks.readthedocs.io/en/latest/tutorial_notebooks/tutorial2/Introduction_to_PyTorch.html)
