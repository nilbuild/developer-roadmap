# Streaming vs Broadcast

Streaming sends data as a continuous flow from one endpoint to another, as TCP does. Broadcast sends a single packet to all devices on a network segment simultaneously, using a special address. Game servers may use multicast or broadcast for local network discovery but typically stream game state to each connected client individually.
