# TCP

TCP (Transmission Control Protocol) is a connection-oriented transport layer protocol that guarantees ordered, reliable delivery of data between two endpoints. It handles retransmission, flow control, and congestion management automatically, which makes it suitable for game features where data loss is unacceptable, such as chat or matchmaking, but less ideal for latency-sensitive state updates.
