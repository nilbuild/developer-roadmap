# pthread

pthreads (POSIX Threads) is the standard threading API on Unix-like systems. It provides functions for creating and joining threads, as well as synchronization primitives like mutexes, condition variables, and read-write locks used extensively in game server code.

Visit the following resources to learn more:

- [@article@POSIX Threads Programming - LLNL HPC Tutorials](https://hpc-tutorials.llnl.gov/posix/)
- [@article@POSIX thread (pthread) libraries - CMU](https://www.cs.cmu.edu/afs/cs/academic/class/15492-f07/www/pthreads.html)
- [@article@Multi-Threaded Programming with Pthreads - Bogotobogo](https://www.bogotobogo.com/cplusplus/multithreading_pthread.php)
