# Akka (Java)

Akka is a Scala/Java toolkit for building concurrent and distributed systems using the Actor Model. Its actor hierarchy enables fault isolation through supervision, and Akka Cluster supports building distributed game server infrastructure that can span multiple machines.

Visit the following resources to learn more:

- [@official@Akka Documentation](https://doc.akka.io/index.html)
- [@official@Introduction to Actors - Akka Docs](https://doc.akka.io/libraries/akka-core/current/typed/actors.html)
- [@official@Java Akka - Play Framework Documentation](https://www.playframework.com/documentation/2.9.x/JavaAkka)
