# RPC / REST

RPC (Remote Procedure Call) and REST are two architectural styles for inter-service communication. RPC systems like gRPC invoke remote functions directly with typed interfaces; REST uses HTTP verbs and resource URLs. Game backends use both, often REST for external APIs and gRPC for internal microservice communication.
