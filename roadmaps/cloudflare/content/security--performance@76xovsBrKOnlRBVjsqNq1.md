# Security & Performance
 
Cloudflare provides a range of security and performance features that apply to traffic passing through its network. Workers can programmatically interact with these features, applying custom logic that complements or extends Cloudflare's built-in protections.

Visit the following resources to learn more:

- [@official@Application Security & Performance Solutions - Cloudflare](https://www.cloudflare.com/application-services/solutions/)
- [@official@Cloudflare Security Architecture](https://developers.cloudflare.com/reference-architecture/architectures/security/)
