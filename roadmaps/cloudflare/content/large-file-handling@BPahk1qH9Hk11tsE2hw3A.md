# Large File Handling
 
R2 supports multipart uploads for large files, splitting them into chunks that are uploaded in parallel and assembled on completion. Workers can initiate, manage, and complete multipart uploads using the R2 API.

Visit the following resources to learn more:

- [@official@Resumable and Large Files · Cloudflare Stream](https://developers.cloudflare.com/stream/uploading-videos/resumable-uploads/)
- [@official@Cloudflare R2 Limits](https://developers.cloudflare.com/r2/platform/limits/)
